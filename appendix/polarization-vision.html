偏振视觉：海鸟如何看穿水面 Polarization Vision

海鸥能看见海里的鱼吗？能——但靠的不是紫外。陆地上红隼靠紫外追踪鼠尿有效，是因为空气里紫外能自由传播；而水会强烈吸收紫外（表层 1 米内所剩无几）。海鸟、海龟、章鱼等水下捕食者真正的杀手锏是偏振视觉 (polarization vision)：滤掉水面眩光、看穿水面。本附录讲清"看鱼"背后的物理——光在介质中的吸收、菲涅尔反射、偏振、斯涅耳窗，以及一场捕食者与猎物间的视觉军备竞赛。Seabirds see fish not via UV (water blocks it) but via polarization vision that cuts water-surface glare.

🎯 学习目标 Learning Objectives

  • 说明为何紫外在水下没用（水吸收紫外），与陆地上的紫外戏法形成对比。
  • 讲清水对可见光的选择性吸收（红先没、蓝绿穿透深）→ 水下动物的视色素调谐在蓝绿。
  • 解释菲涅尔反射：掠视水面时反射率趋近 1（眩光遮眼），陡视时透射大、看得清水下。
  • 说明偏振视觉如何滤眩光、靠偏振对比发现鱼/浮游生物。
  • 理解斯涅耳窗（临界角 \(48.6^{\circ}\)）与"陡俯冲"的关系，以及鱼的反荫蔽 (counter-shading)。

📖 核心物理 Core Physics

① 为什么不是紫外？——水吸收紫外

纯水对紫外的吸收极强，UVA 在表层约 1 米内就被吃掉大半，UVB/UVC 更是厘米级。所以海里的紫外通道基本作废——陆地上的"紫外尿迹"戏法在水下不成立。介质决定了哪个隐藏通道可用。

② 水对可见光的选择性吸收 → 蓝绿世界

水把红光（\(\sim650\,\unit{nm}\)）在几米内吸收，橙黄次之，蓝绿（\(\sim450\!\sim\!500\,\unit{nm}\)）穿透最深（清水可达上百米）。所以水下是一片蓝绿，鱼和潜水动物的视色素（视紫质 rhodopsin）都调谐在蓝绿，以在水下获得最多信息。

③ 菲涅尔反射：掠视 = 眩光，陡视 = 看穿

光在空气-水界面，一部分透射（进水）、一部分反射（眩光）。反射比例由菲涅尔公式决定：

\[ R=\frac{R_s+R_p}{2},\qquad R_s=\!\left|\frac{n_1\cos\theta_i-n_2\cos\theta_t}{n_1\cos\theta_i+n_2\cos\theta_t}\right|^{2},\quad R_p=\!\left|\frac{n_1\cos\theta_t-n_2\cos\theta_i}{n_1\cos\theta_t+n_2\cos\theta_i}\right|^{2} \]

正入射时 \(R\approx2\%\)（几乎全透射，看得清水下）；掠射（\(\theta_i\to90^{\circ}\)）时 \(R\to1\)（水面如镜，只见天空眩光）。所以从陡角度俯视才看得见水下，斜眼一瞥全是眩光——这正是燕鸥、鲣鸟近乎垂直扎水俯冲的物理原因。

④ 真正的超能力：偏振视觉

水面反射的眩光是高度偏振的（尤其布儒斯特角 \(\theta_B\approx53^{\circ}\) 附近，反射光几乎全偏振）。鸟、海龟、章鱼、螳螂虾的一些视锥能感知光的偏振方向（电矢量），相当于自带偏振太阳镜：

  • 滤眩光：屏蔽偏振的反射眩光 → 看穿水面；
  • 偏振对比：透明或伪装的鱼、浮游生物会改变透射/散射光的偏振态，在偏振通道里露出马脚。

⑤ 斯涅耳窗与反荫蔽

水下看上方，整个天空被压缩进一个 \(97^{\circ}\) 的斯涅耳窗 (Snell's window)（临界角 \(\theta_c=\arcsin(1/1.33)\approx48.6^{\circ}\)）；窗外是全反射的水下暗景。从空中看水下则反之：陡视看得见、掠视是眩光。

鱼也没坐以待毙——反荫蔽 (counter-shading)：背暗、腹白。从上方看，深背融入幽暗深水；从下方看，白腹融进明亮水面。这是被捕食者对"被看见"的直接反制。

🔭 推导 Derivation：临界角与"看进水"的极限

由斯涅尔定律 \(n_1\sin\theta_i=n_2\sin\theta_t\)，水下(\(n_2=1.33\))的光要射入空气(\(n_1=1\))，最大 \(\theta_t\) 满足 \(\sin\theta_t=1\)，对应水下 \(\theta_c=\arcsin(1/1.33)=48.6^{\circ}\)。超过此角的光在界面全反射 (TIR) 回水下——这就是斯涅耳窗的边界。

对空中观察者：能"看进水"的有效角度也受这套折射约束；越接近正下方、透射越大（菲涅尔 \(T\to1\)），越能看见水下；越掠射、反射眩光越强（\(R\to1\)）。故海鸟陡俯冲以最大化透射、最小化眩光。

⚠️ 常见误区 Common Pitfalls

  • 误区："海鸟靠紫外看鱼。"
    纠正：水吸收紫外，水下紫外通道作废；靠的是偏振视觉 + 蓝绿视觉 + 陡俯冲。
  • 误区："水面反光只是好看，不影响看鱼。"
    纠正：掠视时反射率趋近 1，眩光完全遮住水下；必须陡视或用偏振滤光。
  • 误区："水里什么颜色都有。"
    纠正：红光几米就没，水下是蓝绿主导；红鱼在深处看起来发黑。
  • 误区："鱼随便就能被看见。"
    纠正：反荫蔽 + 浑浊 + 深度都降低可见性；这是捕食者与猎物的视觉军备竞赛。
  • 误区："偏振和颜色是一回事。"
    纠正：颜色=波长，偏振=电矢量方向，是光的不同维度；偏振视觉是独立于色觉的第三通道。

🎛️ 互动仿真 Interactive Simulation：看穿水面

侧视：空气在上、水在下，水面中央有一条反荫蔽的鱼（背暗腹白）。眼睛从角度 \(\phi\)（相对竖直）看水面。绿线=透射（看进水见鱼），强度 ∝ 透射率 \(T\)；红线=反射眩光，强度 ∝ 反射率 \(R\)（菲涅尔），且是偏振的。拖 视角 \(\phi\)：陡视 \(T\) 大→看见鱼；掠视 \(R\) 大→眩光遮眼（海鸟因此陡俯冲）。
