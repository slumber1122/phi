光子的产生 How Photons Are Produced

"光子是怎么产生的？"答案只有一句话：带电系统释放能量时，就以电磁辐射的形式带走，每一份量子化的辐射就是一个光子。它有两种等价描述——经典图像里"加速的电荷会辐射"，量子图像里"系统从高能态跃迁到低能态，放出光子 \(h\nu=\Delta E\)"。本附录把各种产生机制列成一张表，并用一个光谱选择器直观展示：能量从哪里来，决定了光谱长什么样。A photon is emitted whenever a charged system releases energy; the energy source (thermal, a level transition, acceleration, annihilation…) determines the spectrum.

🎯 学习目标 Learning Objectives

  • 掌握产生光子的统一判据：加速电荷辐射（经典）/ \(\Delta E=h\nu\) 跃迁（量子）。
  • 区分连续谱（热辐射、轫致、同步）与分立谱（原子线状谱、核 γ、湮没单能峰）的物理根源。
  • 由 \(E=h\nu=hc/\lambda\) 在光子能量与波长间换算（如 \(1240\,\unit{nm\cdot eV}/\lambda\)）。
  • 说明常见机制：黑体辐射、原子跃迁、激光、轫致辐射、同步辐射、切伦科夫、湮没、核 γ。
  • 理解"做一个光子"的不同层级：普通光源（多光子）→ 衰减法 → heralded 单光子源（SPDC）。

📖 核心物理 Core Physics

无论哪种机制，光子的能量都由释放它的过程决定：

\[ E_\gamma = h\nu = \frac{hc}{\lambda},\qquad hc = 1240\,\unit{nm\cdot eV} \]

对量子跃迁，光子能量恰为两能级之差：

\[ h\nu = E_2 - E_1 \]

对经典加速辐射，单个电荷的辐射功率由拉莫尔公式 \(P=\dfrac{q^{2}a^{2}}{6\pi\varepsilon_0 c^{2}}\) 给出（\(a\) 为加速度）——加速越剧烈，辐射越强；这类过程给出连续谱。

连续 vs 分立，根源在于"能级是否分立"。原子/原子核的内部能级是量子化的，跃迁给出特定能量的光子 → 分立谱线；而热运动、电子被核减速、相对论电子在磁场中回旋等过程涉及连续可变的能量释放 → 连续谱。记住这一条，下面的表就一目了然。

🔴 激光是怎么产生的 How a Laser Is Made

激光 (laser = Light Amplification by Stimulated Emission of Radiation) 仍是机制 ③（受激辐射），但它需要一套工程装置把"自发随机发光"变成"相干放大"。三要素：

  1. 增益介质 (gain medium)：具有合适能级的原子/分子/离子或固体——如 Nd:YAG 晶体、He-Ne 气体、半导体 p-n 结、CO₂ 气体、Ti:蓝宝石。
  2. 泵浦 (pump)：把电子抽到上能级的能量源——闪光灯、气体放电、电流注入（二极管）、或另一束激光（DPSS 二极管泵浦固态）。
  3. 光学谐振腔 (optical cavity)：两面相对的镜（一全反、一部分透射 = 输出镜），光在其中往返穿过增益介质，每次受激辐射放大；增益超过损耗即起振。
粒子数反转 (population inversion)。常态下低能级粒子更多（玻尔兹曼分布）。泵浦必须把更多粒子抬到上能级、并让下能级迅速排空（常用三能级 / 四能级方案），形成"反转"。一旦反转，一个路过光子就能诱发一串完全相同的光子（同频率、相位、方向、偏振）→ 雪崩放大 → 输出相干、单色、定向的光束（连续或脉冲，最短可达飞秒级，靠锁模 mode-locking）。

UV 紫外激光怎么造

紫外光子能量更高（\(\sim3\!\sim\!10\,\unit{eV}\)），要直接产生 UV 激光，"上-下能级差"必须落在 UV 区。两条主流路线：

A. 直接 UV 增益介质

  • 准分子激光 (excimer)：稀有气体（Ar、Kr、Xe）+ 卤素（F、Cl）。基态下不结合，但放电激发后形成短暂结合的"准分子"，它退激发就释放一个 UV 光子。典型：ArF 193 nm、KrF 248 nm、XeCl 308 nm、F₂ 157 nm。用途：LASIK 近视手术（193 nm 光子直接打断角膜分子键、几乎无热损伤）与半导体光刻（193 nm ArF 浸没式光刻定义了多数现代芯片的线宽）。
  • 氮气激光 (N₂)：337 nm，结构简单、脉冲工作。
  • UV 半导体二极管：GaN 基，365–405 nm，用于 UV 固化、检测（小型化、电注入）。

B. 非线性频率转换（倍频 / 和频）：用一块非线性晶体（BBO、LBO、KDP、CLBO）把 IR/可见激光的频率"翻倍 / 三倍"。一束 Nd:YAG 的 1064 nm 红外光经级联倍频可得绿光与 UV：

\[ \underbrace{1064\,\unit{nm}}_{\text{Nd:YAG (IR)}} \;\to\; \underbrace{532\,\unit{nm}}_{\text{倍频 SHG (绿)}} \;\to\; \underbrace{355\,\unit{nm}}_{\text{三倍频 THG (UV)}} \;\to\; \underbrace{266\,\unit{nm}}_{\text{四倍频 FHG (深 UV)}} \]

很多"UV 固态激光器"就是这么做的：二极管泵浦 Nd:YAG / YVO₄ + 级联非线性晶体。连常见的"绿激光笔"也是 DPSS——1064 nm 经倍频得到 532 nm，并非直接发绿光的二极管。

C. 深紫外 / 极紫外 (DUV / EUV) —— 芯片制造的极致

最先进的芯片（5 nm、3 nm 节点）用 EUV 13.5 nm 光刻：用高功率 CO₂ 激光每秒数万次轰击下落的锡 (Sn) 液滴，形成锡等离子体辐射 13.5 nm 的 EUV，再用一套极其复杂的反射镜收集成像。EUV 光刻机是目前人类最精密的制造设备之一——光子能量高达 \(\sim92\,\unit{eV}\)。

把激光和"光子产生"连起来：无论哪种激光，发光那一步仍是原子/分子的受激跃迁（\(h\nu=E_2-E_1\)）。UV 激光的"紫外"要么来自更大的能级差（准分子），要么靠非线性晶体把频率翻倍——本质上都是在提高单个光子的能量 \(h\nu\)。

🔭 推导 Derivation

跃迁 → 谱线。氢原子能级 \(E_n=-13.6\,\unit{eV}/n^{2}\)。巴耳末系（\(n\to2\)）第一条 \(n=3\to2\)：

\[ \Delta E=13.6\!\left(\frac{1}{2^{2}}-\frac{1}{3^{2}}\right)=13.6\!\left(\frac{1}{4}-\frac{1}{9}\right)=13.6\times0.1389=1.89\,\unit{eV} \]

\(\lambda=hc/\Delta E=1240/1.89=656\,\unit{nm}\)（红色 Hα）。能级分立 → 谱线分立。

黑体峰值随温度移动（维恩）。按能量计的 Planck 谱 \(B(E)\propto E^{3}/(e^{E/kT}-1)\) 在 \(E_{\text{peak}}\approx2.82\,kT\) 处取极大。\(T\) 升高 → 峰向高能（短波）移动：\(T=3000\,\unit{K}\)（红巨星/灯泡）峰在红外，\(T=5800\,\unit{K}\)（太阳）峰在近红外/可见边缘，\(T=10000\,\unit{K}\)（蓝白星）峰移到蓝/紫外——这正是恒星颜色的由来。

轫致辐射截止。X 光管中电子被电压 \(V\) 加速，最多把全部动能 \(eV\) 交给一个光子，故连续谱有硬截止 \(E_{\max}=eV\)；\(V=30\,\unit{kV}\Rightarrow E_{\max}=30\,\unit{keV}\)。

湮没单能峰。正负电子对静止湮没：\(e^{+}e^{-}\to2\gamma\)，能量守恒给每个光子 \(E_\gamma=m_ec^{2}=511\,\unit{keV}\)——一个尖锐的单能峰（PET 成像就靠它）。

✏️ 典型例题 Worked Examples

例 1　钠黄光的能量

钠灯 D 线 \(\lambda=589\,\unit{nm}\)。求光子能量（eV 与 J）。

解：\(E=hc/\lambda=1240/589=2.10\,\unit{eV}\)。

\(E=2.10\times1.602\times10^{-19}=3.37\times10^{-19}\,\unit{J}\)。

\(2.10\,\unit{eV}\)（\(3.37\times10^{-19}\,\unit{J}\)）。

例 2　黑体峰位（太阳）

太阳 \(T\approx5800\,\unit{K}\)。按维恩波长定律 \(\lambda_{\max}T=2.898\times10^{-3}\,\unit{m\,K}\)，求峰值波长与对应能量。

解：\(\lambda_{\max}=2.898\times10^{-3}/5800=5.00\times10^{-7}\,\unit{m}=500\,\unit{nm}\)（绿/可见）。

\(E=1240/500=2.48\,\unit{eV}\)。

\(\lambda_{\max}\approx500\,\unit{nm}\)，\(E\approx2.5\,\unit{eV}\)——恰在可见光带（太阳光谱在此最丰）。

例 3　X 光管的最短波长

X 光管 \(V=50\,\unit{kV}\)。求轫致谱的最短波长（截止）。

解：截止 \(E_{\max}=eV=50\,\unit{keV}\)；\(\lambda_{\min}=hc/E=1240/(5.0\times10^{4})=0.0248\,\unit{nm}=0.248\,\unit{Å}\)。

\(\lambda_{\min}\approx0.025\,\unit{nm}\)（硬 X 射线）——电压越高，X 射线越"硬"。

⚠️ 常见误区 Common Pitfalls

  • 误区："光子只是可见光。"
    纠正：光子跨越整个电磁谱——从射电、微波、红外、可见、紫外、X 到 γ，区别只是能量 \(h\nu\)。可见光只是其中很窄一段（约 \(1.6\!\sim\!3.3\,\unit{eV}\)）。
  • 误区："激光是用别的方法造光子。"
    纠正：激光仍是受激跃迁（原子退激发），只是受入射光子诱导、产生同相光子；能量来源仍是能级差。
  • 误区："连续谱和分立谱是测量误差。"
    纠正：连续 vs 分立源自物理本身——前者来自连续可变的能量释放（加速、热），后者来自量子化能级的跃迁。
  • 误区："湮没是凭空产生能量。"
    纠正：能量来自粒子的静质量（\(E=mc^{2}\)），质能守恒；\(511\,\unit{keV}\) 恰为电子静能。
  • 误区："单个光子有颜色。"
    纠正：颜色是大量光子的统计/感知；单个光子只有确定的能量（频率），"颜色"是大脑对该能量的诠释。

🧮 练习题 Practice Problems

1. 调频广播 \(f=100\,\unit{MHz}\)，求光子能量。它为什么不像可见光那样显得"颗粒化"？
\(E=hf\)；与室温 \(kT\) 比较。
\(E=hf=(4.14\times10^{-15})(10^{8})=4.14\times10^{-7}\,\unit{eV}\)，远小于室温 \(kT\approx0.026\,\unit{eV}\)，故量子性被热涨落淹没，表现为经典波。\(\sim4\times10^{-7}\,\unit{eV}\)；量子能 \(\ll kT\)。
2. 黑体温度从 \(3000\,\unit{K}\) 升到 \(6000\,\unit{K}\)，峰值波长如何变？峰值光子能量如何变？
维恩 \(\lambda_{\max}\propto1/T\)，温度翻倍 → 峰值波长减半；能量 \(E\propto T\)，翻倍。\(\lambda_{\max}\) 减半，\(E_{\text{peak}}\) 加倍（峰蓝移）。
3. 一个动能为 \(2\,\unit{MeV}\) 的正电子与静止电子湮没，产生的 γ 光子能量上限是多少？
能量守恒：总能量 \(=2m_ec^{2}+K=2(511)+2000=3022\,\unit{keV}\)，分给两个光子；单光子上限（对头撞时一个光子拿走几乎全部）约 \(3022\,\unit{keV}\)，下限（两光子均分）约 \(1511\,\unit{keV}\)。静止湮没则为对称的 \(511\,\unit{keV}\)。单光子能量在 \(\sim1.5\!\sim\!3.0\,\unit{MeV}\) 间（视动量分布）。
4. （概念）为什么把普通光"极度衰减"不算严格单光子源，而 SPDC 算？
衰减只是降低热光的平均光子数，但热光是混杂光（光子成团到达），无法保证"一次一个"；SPDC 探测到其中一个下转换光子即"宣告"另一个必定存在，且可测反聚束 \(g^{(2)}(0)<1/2\) 严格证明单光子。衰减=统计平均；SPDC=可宣告、反聚束。
