线性代数 Linear Algebra

🎯 学习目标 Learning Objectives

学完本章后，你将能够：

  • 把矢量 (vector) 与矩阵 (matrix) 视作线性代数的基本对象，写出矩阵——矢量乘法 \(A\vec{x}\) 与矩阵——矩阵乘法 \(AB\) 的行乘列规则，并解释为何 \(AB\neq BA\) 一般成立。
  • 计算 \(2\times 2\)、\(3\times 3\) 矩阵的行列式 (determinant)，解释 \(\det A\) 是 \(A\) 作用于空间时的面积/体积缩放因子，并说明 \(\det A=0\) 与不可逆 (singular) 的等价性。
  • 对 \(2\times 2\) 矩阵直接写出逆矩阵 (inverse) \(A^{-1}\)，并用 \(AA^{-1}=I\) 验证；用高斯消元 (Gaussian elimination) 解 \(3\times 3\) 线性方程组。
  • 由 本征值方程 \(A\vec{v}=\lambda\vec{v}\) 与特征多项式 \(\det(A-\lambda I)=0\) 求 \(2\times 2\) 矩阵的本征值 (eigenvalue) 与本征矢量 (eigenvector)。
  • 对对称矩阵 \(S=S^{\mathsf{T}}\) 完成正交对角化 \(S=ODO^{\mathsf{T}}\)，并指出对称矩阵的本征矢量彼此正交。
  • 把上述工具用到三个物理情境：(i) 耦合振子与简正模 (coupled oscillators / normal modes)——对角化刚度矩阵得到简正频率；(ii) 惯量张量 (inertia tensor)——本征矢量即主轴、本征值即主转动惯量；(iii) 一句话预告量子力学——可观测量算符的本征矢 = 本征态，本征值 = 测量可能结果。

📖 核心概念 Core Concepts

1. 矢量与矩阵 Vectors & Matrices

物理中的 \(n\) 维矢量 (column vector) 写作 \(\vec{x}=(x_{1},x_{2},\ldots,x_{n})^{\mathsf{T}}\)。一个 \(m\times n\) 矩阵 (matrix) \(A\) 是 \(m\) 行 \(n\) 列的数表 \(A_{ij}\)，可视为把 \(\mathbb{R}^{n}\) 中矢量映射到 \(\mathbb{R}^{m}\) 的线性变换 (linear transformation)：\(A\vec{x}\) 的第 \(i\) 分量是 \(A\) 的第 \(i\) 行与 \(\vec{x}\) 的点积 (dot product)。

\[ (A\vec{x})_{i}=\sum_{j=1}^{n}A_{ij}x_{j} \]

矩阵乘法 (matrix multiplication) \(AB\) 定义为 \((AB)_{ij}=\sum_{k}A_{ik}B_{kj}\)——"行乘列"。即用 \(A\) 的行去点乘 \(B\) 的列。乘积只有当 \(A\) 的列数 = \(B\) 的行数时才有定义。

\[ [AB]_{ij}=A_{i1}B_{1j}+A_{i2}B_{2j}+\cdots=\sum_{k}A_{ik}B_{kj} \]

关键性质：矩阵乘法满足结合律 \((AB)C=A(BC)\)、不满足交换律 \(AB\neq BA\)（一般情形）、对加法有分配律 \(A(B+C)=AB+AC\)。当 \(AB=BA\) 时称 \(A,B\) 可对易 (commute)。转置 (transpose) \(A^{\mathsf{T}}\) 满足 \((AB)^{\mathsf{T}}=B^{\mathsf{T}}A^{\mathsf{T}}\)（顺序颠倒！）。

column vector (列矢量), matrix (矩阵), linear transformation (线性变换), matrix multiplication (矩阵乘法), transpose \(A^{\mathsf{T}}\) (转置), commute (可对易)

2. 行列式：几何与代数 Determinant — Geometry & Algebra

行列式 \(\det A\)（亦记作 \(|A|\)）是方阵的一个数，几何上等于 "\(A\) 把空间缩放了多少倍"：对 \(2\times 2\)，是由 \(A\) 的两个列矢量张成的平行四边形的有向面积；对 \(3\times 3\)，是平行六面体的有向体积。

\[ \det\!\begin{pmatrix}a&b\\c&d\end{pmatrix}=ad-bc \]

\(3\times 3\) 情形用 Laplace 展开（沿第一行）：

\[ \det\!\begin{pmatrix}a&b&c\\d&e&f\\g&h&i\end{pmatrix}=a(ei-fh)-b(di-fg)+c(dh-eg) \]

三条核心性质：(i) \(\det(AB)=\det A\cdot\det B\)；(ii) \(\det A^{\mathsf{T}}=\det A\)；(iii) \(\det A=0\iff A\) 不可逆（"压扁"了空间，丢失了维度信息，无复原之路）。若 \(\det A>0\)，\(A\) 保向（旋转 + 伸缩）；若 \(\det A<0\)，\(A\) 反向（含一次反射）；\(\det A=\pm 1\) 时面积/体积不变。

determinant \(\det A\) (行列式), oriented area/volume (有向面积/体积), singular (奇异/不可逆), Laplace expansion (拉普拉斯展开)

3. 逆矩阵 Matrix Inverse

若存在方阵 \(A^{-1}\) 使得 \(AA^{-1}=A^{-1}A=I\)（\(I\) 为单位矩阵），则 \(A\) 可逆 (invertible)。可逆的充要条件是 \(\det A\neq 0\)。对 \(2\times 2\)：

\[ \boxed{\;A=\begin{pmatrix}a&b\\c&d\end{pmatrix},\qquad A^{-1}=\frac{1}{ad-bc}\begin{pmatrix}d&-b\\-c&a\end{pmatrix}=\frac{1}{\det A}\begin{pmatrix}d&-b\\-c&a\end{pmatrix}\;} \]

口诀："主对角 swap，副对角 negate，再除以 \(\det\)"。注意 \((AB)^{-1}=B^{-1}A^{-1}\)（顺序颠倒——"穿袜再穿鞋，反过来脱"）。

invertible (可逆), inverse \(A^{-1}\) (逆矩阵), identity matrix \(I\) (单位矩阵)

4. 解线性方程组：高斯消元 Solving Linear Systems — Gaussian Elimination

线性方程组 \(A\vec{x}=\vec{b}\) 的标准解法是高斯消元 (Gaussian elimination)：对增广矩阵 \([A\,|\,\vec{b}]\) 反复做三种初等行变换 (elementary row operations)：(1) 两行交换；(2) 一行乘非零常数；(3) 一行加上另一行的倍数。目标：把 \(A\) 化为上三角 (upper triangular) 形式（前向消元），然后从最后一行开始回代 (back-substitution) 求解。

解的存在唯一性（方阵情形 \(n\times n\)）：\(\det A\neq 0\) \(\iff\) 唯一解 \(\vec{x}=A^{-1}\vec{b}\)；\(\det A=0\) 时要么无解（不相容）要么无穷多解（\(\vec{b}\) 落在 \(A\) 的列空间里时）。

Gaussian elimination (高斯消元), augmented matrix (增广矩阵), elementary row operation (初等行变换), back-substitution (回代), upper triangular (上三角)

5. 本征值与本征矢量 Eigenvalues & Eigenvectors

对方阵 \(A\)，若存在非零矢量 \(\vec{v}\) 与标量 \(\lambda\) 使 \(A\vec{v}=\lambda\vec{v}\)，则称 \(\vec{v}\) 为 \(A\) 的本征矢量 (eigenvector)、\(\lambda\) 为对应的本征值 (eigenvalue)。几何含义：本征矢量是方向不变的方向——\(A\) 作用其上只伸缩（\(|\lambda|>1\) 放大、\(|\lambda|<1\) 缩小、\(\lambda<0\) 反向再伸缩、\(\lambda=0\) 压扁到原点）。

本征方程 \((A-\lambda I)\vec{v}=\vec{0}\) 有非零解 \(\iff\det(A-\lambda I)=0\)。这是 \(\lambda\) 的 \(n\) 次多项式，称为特征多项式 (characteristic polynomial)：

\[ \boxed{\;\det(A-\lambda I)=0\quad\Longrightarrow\quad\text{本征值}\;\lambda_{1},\ldots,\lambda_{n}\;} \]

对 \(2\times 2\) 矩阵 \(A=\begin{pmatrix}a&b\\c&d\end{pmatrix}\)，特征多项式为：

\[ \lambda^{2}-(a+d)\,\lambda+(ad-bc)=0,\qquad \lambda^{2}-(\mathrm{tr}\,A)\,\lambda+\det A=0 \]

即本征值只依赖 迹 (trace) \(\mathrm{tr}\,A=a+d\) 与 \(\det A\) 两个不变量：\(\lambda_{1,2}=\tfrac{1}{2}\bigl[\mathrm{tr}\,A\pm\sqrt{(\mathrm{tr}\,A)^{2}-4\det A}\bigr]\)。判别式 \(\Delta=(a-d)^{2}+4bc<0\) 时本征值为共轭复数——\(A\) 含旋转分量（无实的"不动方向"）。求出 \(\lambda\) 后，代回 \((A-\lambda I)\vec{v}=\vec{0}\) 解出本征矢量。

eigenvalue \(\lambda\) (本征值/特征值), eigenvector \(\vec{v}\) (本征矢量/特征矢量), characteristic polynomial \(\det(A-\lambda I)\) (特征多项式), trace \(\mathrm{tr}\,A\) (迹)

6. 对角化与对称矩阵 Diagonalization; Symmetric Matrices

若 \(n\times n\) 矩阵 \(A\) 有 \(n\) 个线性无关的本征矢量，把它们作为列排成 \(P=[\vec{v}_{1}\,\vec{v}_{2}\,\cdots\,\vec{v}_{n}]\)，则：

\[ \boxed{\;A=PDP^{-1},\qquad D=\mathrm{diag}(\lambda_{1},\lambda_{2},\ldots,\lambda_{n})\;} \]

此时 \(A\) 称为可对角化 (diagonalizable)，\(D\) 是本征值在对角线上的矩阵。对称矩阵 \(S=S^{\mathsf{T}}\) 永远可对角化（"实谱定理"），且本征值全实、不同本征值的本征矢量两两正交。若把本征矢量归一化 (normalize) 后排成正交矩阵 \(O\)（满足 \(O^{\mathsf{T}}O=I\)），则：

\[ S=ODO^{\mathsf{T}},\qquad O^{\mathsf{T}}=O^{-1} \]

物理意义：\(O\) 是一次旋转（"换到本征矢量为基的坐标系"），\(D\) 在新基下只是沿各轴独立伸缩。这就是"找主轴"(principal axes) 的过程。线性代数的事实：并非所有矩阵都可对角化（亏损矩阵 defective，如剪切的 \(\begin{pmatrix}1&1\\0&1\end{pmatrix}\) 只有一个本征矢量），但物理上常遇到的对称/厄米矩阵总是好矩阵。

diagonalizable (可对角化), symmetric matrix \(S=S^{\mathsf{T}}\) (对称矩阵), orthogonal matrix \(O\) (正交矩阵), principal axes (主轴), defective (亏损/不可对角化)

7. 物理应用一：耦合振子与简正模 Coupled Oscillators & Normal Modes

两质量均为 \(m\) 的振子由弹簧耦合：左右两根外弹簧劲度 \(k\)，中间耦合弹簧 \(k_{c}\)。位移 \(x_{1},x_{2}\)，则

\[ m\ddot{x}_{1}=-(k+k_{c})x_{1}+k_{c}x_{2},\qquad m\ddot{x}_{2}=k_{c}x_{1}-(k+k_{c})x_{2} \]

写成矩阵形式 \(m\ddot{\vec{x}}=-K\vec{x}\)，其中刚度矩阵 (stiffness matrix)：

\[ K=\begin{pmatrix}k+k_{c} & -k_{c}\\ -k_{c} & k+k_{c}\end{pmatrix} \]

\(K\) 是对称矩阵，正交对角化给出本征矢量 \((1,1)/\sqrt{2}\)（同相 mode，弹簧 \(k_{c}\) 不被拉伸，本征值 \(k\)）与 \((1,-1)/\sqrt{2}\)（反相 mode，\(k_{c}\) 被拉伸最厉害，本征值 \(k+2k_{c}\)）。设解 \(\vec{x}(t)=\vec{a}\cos(\omega t)\)，得 \(K\vec{a}=\omega^{2}m\,\vec{a}\)——本征值问题！简正频率：

\[ \boxed{\;\omega_{1}=\sqrt{\frac{k+2k_{c}}{m}}\;\text{(反相)},\qquad \omega_{2}=\sqrt{\frac{k}{m}}\;\text{(同相)}\;} \]

一般运动是两个简正模式的任意叠加。这就是第 3 章/第 8 章简正模式的代数根源：耦合系统的运动方程在主轴坐标下解耦为独立简谐振子。

8. 物理应用二：惯量张量 Inertia Tensor

刚体绕原点的惯量张量 (inertia tensor) 是对称矩阵：

\[ I_{ij}=\int\rho(\vec{r})\bigl(r^{2}\delta_{ij}-x_{i}x_{j}\bigr)\,\mathrm{d}^{3}r\;\;\Longleftrightarrow\;\;I=\begin{pmatrix}I_{xx}&I_{xy}&I_{xz}\\I_{yx}&I_{yy}&I_{yz}\\I_{zx}&I_{zy}&I_{zz}\end{pmatrix} \]

其中 \(I_{xx}=\int\rho\,(y^{2}+z^{2})\,\mathrm{d}^{3}r\)（绕 \(x\) 轴的转动惯量），\(I_{xy}=-\int\rho\,xy\,\mathrm{d}^{3}r\)（惯量积，negative sign convention）。角动量与角速度关系 \(\vec{L}=I\vec{\omega}\)——一般 \(\vec{L}\) 不沿 \(\vec{\omega}\)！把 \(I\) 正交对角化：本征矢量 = 主轴 (principal axes)，本征值 = 主转动惯量 \(I_{1},I_{2},I_{3}\)。在主轴坐标下 \(I=\mathrm{diag}(I_{1},I_{2},I_{3})\)，\(\vec{L}\) 与 \(\vec{\omega}\) 沿主轴分量成正比。这是第 6 章刚体转动的核心代数。

9. 物理应用三：量子力学算符（预告） QM Operators — Preview

在量子力学里，每个物理可观察量 (observable) 由一个厄米算符 (Hermitian operator) \(\hat{A}\)——"实对称矩阵"在无穷维空间的推广——表示。其本征方程 \(\hat{A}\,|\psi_{n}\rangle=a_{n}|\psi_{n}\rangle\) 给出：本征态 \(|\psi_{n}\rangle\) 是测量时确定得到某值的态，本征值 \(a_{n}\) 是测量可能得到的实数值。例如能量本征值方程 \(\hat{H}|\psi_{n}\rangle=E_{n}|\psi_{n}\rangle\) 就是定态薛定谔方程。线性代数的本征值理论，正是量子力学的代数骨架。

Hermitian operator (厄米算符), observable (可观测量), eigenstate (本征态), measurement (测量)

🔭 推导 Derivation

推导 12.1：\(\det(AB)=\det A\cdot\det B\)（\(2\times 2\) 情形）

步骤 1： 设 \(A=\begin{pmatrix}a&b\\c&d\end{pmatrix}\)、\(B=\begin{pmatrix}e&f\\g&h\end{pmatrix}\)。

步骤 2： 矩阵乘积 \(AB=\begin{pmatrix}ae+bg & af+bh\\ce+dg & cf+dh\end{pmatrix}\)。

步骤 3： 直接展开 \(\det(AB)=(ae+bg)(cf+dh)-(af+bh)(ce+dg)\)：

\[ =\underbrace{aecf+aedh+bgcf+bgdh}_{\text{四项}}-\underbrace{(afce+afdg+bhce+bhdg)}_{\text{四项}} \]

步骤 4： \(aecf\) 与 \(afce=aecf\) 相消；\(bgdh\) 与 \(bhdg=bgdh\) 相消。剩下：

\[ \det(AB)=aedh+bgcf-(afdg+bhce)=ad(eh-fg)+bc(gf-eh) \]

步骤 5： 注意 \(gf-eh=-(eh-fg)\)，所以 \(\det(AB)=(ad-bc)(eh-fg)=\det A\cdot\det B\)。证毕。几何解读：先以 \(B\) 把面积乘 \(\det B\)，再以 \(A\) 乘 \(\det A\)，净缩放为乘积。

推导 12.2：\(\det A=0\iff A\) 不可逆

步骤 1（\(\Leftarrow\)）： 若 \(A\) 可逆，\(AA^{-1}=I\)。两边取行列式：\(\det(A)\det(A^{-1})=\det I=1\)，故 \(\det A\neq 0\)（且 \(\det A^{-1}=1/\det A\)）。

步骤 2（\(\Rightarrow\)）： 设 \(\det A=0\)，则 \(A\) 的列矢量 \(\vec{c}_{1},\vec{c}_{2}\) 张成的平行四边形面积为零，意味着 \(\vec{c}_{1},\vec{c}_{2}\) 共线（线性相关）。于是存在非零矢量 \(\vec{v}\)（例如与 \(\vec{c}_{1}\) 在 \(\vec{c}_{2}\) 方向投影的差）使 \(A\vec{v}=\vec{0}\)。

步骤 3： 若 \(A^{-1}\) 存在，左乘 \(A^{-1}\) 得 \(\vec{v}=A^{-1}\vec{0}=\vec{0}\)，矛盾。故 \(A\) 不可逆。证毕。物理解读：\(A\) 把平面"压扁"为一条线，信息丢失，无逆可复原。

推导 12.3：对称矩阵不同本征值的本征矢量正交

步骤 1： 设 \(S=S^{\mathsf{T}}\)，\(S\vec{v}_{1}=\lambda_{1}\vec{v}_{1}\)、\(S\vec{v}_{2}=\lambda_{2}\vec{v}_{2}\)，\(\lambda_{1}\neq\lambda_{2}\)。

步骤 2： 考虑标量 \(\vec{v}_{1}^{\mathsf{T}}S\vec{v}_{2}\)。一方面 \(\vec{v}_{1}^{\mathsf{T}}S\vec{v}_{2}=\vec{v}_{1}^{\mathsf{T}}(\lambda_{2}\vec{v}_{2})=\lambda_{2}\,(\vec{v}_{1}\!\cdot\!\vec{v}_{2})\)。

步骤 3： 另一方面 \(\vec{v}_{1}^{\mathsf{T}}S\vec{v}_{2}=(\vec{v}_{1}^{\mathsf{T}}S)\vec{v}_{2}\)。因 \(S\) 对称，\(\vec{v}_{1}^{\mathsf{T}}S=(S^{\mathsf{T}}\vec{v}_{1})^{\mathsf{T}}=(S\vec{v}_{1})^{\mathsf{T}}=(\lambda_{1}\vec{v}_{1})^{\mathsf{T}}=\lambda_{1}\vec{v}_{1}^{\mathsf{T}}\)。所以 \(\vec{v}_{1}^{\mathsf{T}}S\vec{v}_{2}=\lambda_{1}(\vec{v}_{1}\!\cdot\!\vec{v}_{2})\)。

步骤 4： 两个表达式相等：\(\lambda_{2}(\vec{v}_{1}\!\cdot\!\vec{v}_{2})=\lambda_{1}(\vec{v}_{1}\!\cdot\!\vec{v}_{2})\)，即 \((\lambda_{2}-\lambda_{1})(\vec{v}_{1}\!\cdot\!\vec{v}_{2})=0\)。由 \(\lambda_{1}\neq\lambda_{2}\) 得 \(\vec{v}_{1}\!\cdot\!\vec{v}_{2}=0\)。证毕。这是物理上"主轴总两两正交"的代数根源。

✏️ 典型例题 Worked Examples

例 12.1 用高斯消元解 \(3\times 3\) 线性方程组

解方程组

\[ \begin{cases}x+y+z=6\\2x-y+z=3\\x+2y-z=2\end{cases} \]

解： 写出增广矩阵 \([A\,|\,\vec{b}]\)：

\[ \left(\begin{array}{ccc|c}1&1&1&6\\2&-1&1&3\\1&2&-1&2\end{array}\right) \]

前向消元 1： \(R_{2}\to R_{2}-2R_{1}\)、\(R_{3}\to R_{3}-R_{1}\)（消去第一列下方元素）：

\[ \left(\begin{array}{ccc|c}1&1&1&6\\0&-3&-1&-9\\0&1&-2&-4\end{array}\right) \]

前向消元 2： 为方便，\(R_{2}\leftrightarrow R_{3}\) 交换：

\[ \left(\begin{array}{ccc|c}1&1&1&6\\0&1&-2&-4\\0&-3&-1&-9\end{array}\right) \]

前向消元 3： \(R_{3}\to R_{3}+3R_{2}\)：

\[ \left(\begin{array}{ccc|c}1&1&1&6\\0&1&-2&-4\\0&0&-7&-21\end{array}\right) \]

已得上三角形式。注意中间做过一次行交换 \(R_{2}\leftrightarrow R_{3}\)，故 \(\det A=-\bigl[1\cdot 1\cdot(-7)\bigr]=7\neq 0\)（行交换会改变行列式符号），故唯一解。回代：

由 \(R_{3}\)：\(-7z=-21\Rightarrow z=3\)。

由 \(R_{2}\)：\(y-2z=-4\Rightarrow y-6=-4\Rightarrow y=2\)。

由 \(R_{1}\)：\(x+y+z=6\Rightarrow x+2+3=6\Rightarrow x=1\)。

唯一解 \(\vec{x}=(x,y,z)=(1,\,2,\,3)\)

例 12.2 \(2\times 2\) 行列式、逆矩阵，并用其解 \(A\vec{x}=\vec{b}\)

设 \(A=\begin{pmatrix}3&1\\2&4\end{pmatrix}\)，\(\vec{b}=\begin{pmatrix}5\\6\end{pmatrix}\)。(a) 求 \(\det A\)；(b) 求 \(A^{-1}\) 并用 \(AA^{-1}=I\) 验证；(c) 用 \(A^{-1}\) 解 \(A\vec{x}=\vec{b}\)；(d) 几何上解释 \(\det A\)。

解： (a) \(\det A=ad-bc=3\cdot 4-1\cdot 2=12-2=10\)。

(b) 用公式 \(A^{-1}=\dfrac{1}{\det A}\begin{pmatrix}d&-b\\-c&a\end{pmatrix}\)：

\[ A^{-1}=\frac{1}{10}\begin{pmatrix}4&-1\\-2&3\end{pmatrix}=\begin{pmatrix}0.4&-0.1\\-0.2&0.3\end{pmatrix} \]

验证：\(AA^{-1}=\begin{pmatrix}3&1\\2&4\end{pmatrix}\begin{pmatrix}0.4&-0.1\\-0.2&0.3\end{pmatrix}\)。第 (1,1) 元 \(3(0.4)+1(-0.2)=1.2-0.2=1\) ✓；第 (1,2) 元 \(3(-0.1)+1(0.3)=-0.3+0.3=0\) ✓；第 (2,1) 元 \(2(0.4)+4(-0.2)=0.8-0.8=0\) ✓；第 (2,2) 元 \(2(-0.1)+4(0.3)=-0.2+1.2=1\) ✓。故 \(AA^{-1}=I\)。

(c) \(\vec{x}=A^{-1}\vec{b}=\dfrac{1}{10}\begin{pmatrix}4&-1\\-2&3\end{pmatrix}\begin{pmatrix}5\\6\end{pmatrix}=\dfrac{1}{10}\begin{pmatrix}20-6\\-10+18\end{pmatrix}=\dfrac{1}{10}\begin{pmatrix}14\\8\end{pmatrix}=\begin{pmatrix}1.4\\0.8\end{pmatrix}\)。

验证：\(A\vec{x}=\begin{pmatrix}3&1\\2&4\end{pmatrix}\begin{pmatrix}1.4\\0.8\end{pmatrix}=\begin{pmatrix}4.2+0.8\\2.8+3.2\end{pmatrix}=\begin{pmatrix}5\\6\end{pmatrix}=\vec{b}\) ✓

(d) \(A\) 的两个列矢量 \(\vec{c}_{1}=(3,2)^{\mathsf{T}}\)、\(\vec{c}_{2}=(1,4)^{\mathsf{T}}\) 张成的平行四边形面积为 \(|\det A|=10\)（单位坐标方块面积的 10 倍）。\(\det A>0\) 还说明 \(A\) 保向（无反射）。

\((a)\;\det A=10;\;(b)\;A^{-1}=\tfrac{1}{10}\begin{pmatrix}4&-1\\-2&3\end{pmatrix};\;(c)\;\vec{x}=(1.4,\,0.8);\;(d)\;\text{面积}=10\)

例 12.3 \(2\times 2\) 矩阵的本征值与本征矢量（非对称）

设 \(A=\begin{pmatrix}4&1\\2&3\end{pmatrix}\)。(a) 求本征值；(b) 求对应本征矢量；(c) 验证 \(A\vec{v}=\lambda\vec{v}\)；(d) 这两个本征矢量正交吗？为什么？

解： (a) 迹 \(\mathrm{tr}\,A=4+3=7\)，\(\det A=4\cdot 3-1\cdot 2=10\)。特征多项式 \(\lambda^{2}-7\lambda+10=0\)，因式分解为 \((\lambda-5)(\lambda-2)=0\)，故 \(\lambda_{1}=5,\;\lambda_{2}=2\)。

(b) \(\lambda_{1}=5\)： 解 \((A-5I)\vec{v}=\vec{0}\)，即 \(\begin{pmatrix}-1&1\\2&-2\end{pmatrix}\begin{pmatrix}v_{1}\\v_{2}\end{pmatrix}=\vec{0}\)。第一行 \(-v_{1}+v_{2}=0\Rightarrow v_{2}=v_{1}\)，取 \(\vec{v}_{1}=(1,1)^{\mathsf{T}}\)（或归一化为 \((1,1)/\sqrt{2}\)）。

\(\lambda_{2}=2\)： \((A-2I)\vec{v}=\vec{0}\)，即 \(\begin{pmatrix}2&1\\2&1\end{pmatrix}\begin{pmatrix}v_{1}\\v_{2}\end{pmatrix}=\vec{0}\)。第一行 \(2v_{1}+v_{2}=0\Rightarrow v_{2}=-2v_{1}\)，取 \(\vec{v}_{2}=(1,-2)^{\mathsf{T}}\)。

(c) 验证：\(A\vec{v}_{1}=\begin{pmatrix}4&1\\2&3\end{pmatrix}\begin{pmatrix}1\\1\end{pmatrix}=\begin{pmatrix}5\\5\end{pmatrix}=5\vec{v}_{1}\) ✓

\(A\vec{v}_{2}=\begin{pmatrix}4&1\\2&3\end{pmatrix}\begin{pmatrix}1\\-2\end{pmatrix}=\begin{pmatrix}4-2\\2-6\end{pmatrix}=\begin{pmatrix}2\\-4\end{pmatrix}=2\vec{v}_{2}\) ✓

\((a)\;\lambda_{1}=5,\,\lambda_{2}=2;\;(b)\;\vec{v}_{1}=(1,1),\,\vec{v}_{2}=(1,-2);\;(c)\;\text{已验证};\;(d)\;\text{不正交，因 }A\neq A^{\mathsf{T}}\text{。}\)

例 12.4 耦合振子的简正模（对称矩阵对角化）

两个质量均为 \(m=1.0\,\mathrm{kg}\) 的振子，外弹簧劲度 \(k=6.0\,\mathrm{N/m}\)，耦合弹簧 \(k_{c}=2.0\,\mathrm{N/m}\)。刚度矩阵 \(K=\begin{pmatrix}k+k_{c} & -k_{c}\\ -k_{c} & k+k_{c}\end{pmatrix}=\begin{pmatrix}8&-2\\-2&8\end{pmatrix}\,\mathrm{N/m}\)。(a) 求本征值与本征矢量；(b) 求简正频率；(c) 写出对角化 \(K=ODO^{\mathsf{T}}\)；(d) 若 \(t=0\) 时 \(x_{1}=A,\,x_{2}=0\)，写出之后两质量位移。

解： (a) \(\mathrm{tr}\,K=16\)，\(\det K=64-4=60\)。特征方程 \(\lambda^{2}-16\lambda+60=0\)，\(\lambda=\dfrac{16\pm\sqrt{256-240}}{2}=\dfrac{16\pm 4}{2}\)，即 \(\lambda_{1}=10\)、\(\lambda_{2}=6\)（单位 \(\mathrm{N/m}\)）。

本征矢量：\(\lambda_{1}=10\)：\((K-10I)=\begin{pmatrix}-2&-2\\-2&-2\end{pmatrix}\)，方程 \(-2v_{1}-2v_{2}=0\Rightarrow v_{1}=-v_{2}\)，取归一化 \(\vec{v}_{1}=\dfrac{1}{\sqrt{2}}(1,-1)^{\mathsf{T}}\)（反相 mode）。

\(\lambda_{2}=6\)：\((K-6I)=\begin{pmatrix}2&-2\\-2&2\end{pmatrix}\)，方程 \(2v_{1}-2v_{2}=0\Rightarrow v_{1}=v_{2}\)，取归一化 \(\vec{v}_{2}=\dfrac{1}{\sqrt{2}}(1,1)^{\mathsf{T}}\)（同相 mode）。

检验正交：\(\vec{v}_{1}\cdot\vec{v}_{2}=\tfrac{1}{2}(1\cdot 1+(-1)\cdot 1)=0\) ✓（对称矩阵本征矢量正交，与例 12.3 对照）。

(b) 简正频率：\(\omega_{i}=\sqrt{\lambda_{i}/m}\)：

\[ \omega_{1}=\sqrt{10/1.0}=3.16\,\mathrm{rad/s},\qquad \omega_{2}=\sqrt{6/1.0}=2.45\,\mathrm{rad/s} \]

对应周期 \(T_{1}=2\pi/\omega_{1}=1.99\,\mathrm{s}\)、\(T_{2}=2\pi/\omega_{2}=2.57\,\mathrm{s}\)。反相 mode 频率更高（耦合弹簧被拉伸，提供额外恢复力）——物理上合理。

(c) 把本征矢量作为列排成正交矩阵 \(O=\dfrac{1}{\sqrt{2}}\begin{pmatrix}1&1\\-1&1\end{pmatrix}\)（\(O^{\mathsf{T}}O=I\)，\(O^{\mathsf{T}}=O^{-1}\)），则：

\[ K=ODO^{\mathsf{T}}=\frac{1}{\sqrt{2}}\begin{pmatrix}1&1\\-1&1\end{pmatrix}\begin{pmatrix}10&0\\0&6\end{pmatrix}\frac{1}{\sqrt{2}}\begin{pmatrix}1&-1\\1&1\end{pmatrix} \]

\(O\) 代表把坐标系旋转 \(-45^{\circ}\)（到主轴 \(\vec{v}_{1},\vec{v}_{2}\)）。在主轴坐标 \(q_{1},q_{2}\) 下，运动方程 \(m\ddot{q}_{i}=-\lambda_{i}q_{i}\) 是两个解耦的独立简谐振子。

(d) 初条件 \(\vec{x}(0)=(A,0)^{\mathsf{T}}\)。投影到主轴：\(q_{1}(0)=\vec{v}_{1}\cdot\vec{x}(0)=A/\sqrt{2}\)、\(q_{2}(0)=\vec{v}_{2}\cdot\vec{x}(0)=A/\sqrt{2}\)，且 \(\dot{q}_{i}(0)=0\)。故

\[ \vec{x}(t)=\frac{A}{\sqrt{2}}\vec{v}_{1}\cos\omega_{1}t+\frac{A}{\sqrt{2}}\vec{v}_{2}\cos\omega_{2}t=\frac{A}{2}\begin{pmatrix}1\\-1\end{pmatrix}\cos(3.16\,t)+\frac{A}{2}\begin{pmatrix}1\\1\end{pmatrix}\cos(2.45\,t) \]

即 \(x_{1}(t)=\tfrac{A}{2}[\cos(3.16\,t)+\cos(2.45\,t)]\)，\(x_{2}(t)=\tfrac{A}{2}[\cos(2.45\,t)-\cos(3.16\,t)]\)。两频率之差产生拍 (beat)：能量在两振子间周期性地来回传递。

\((a)\;\lambda_{1}=10,\vec{v}_{1}=\tfrac{1}{\sqrt{2}}(1,-1);\;\lambda_{2}=6,\vec{v}_{2}=\tfrac{1}{\sqrt{2}}(1,1);\;(b)\;\omega_{1}=3.16,\omega_{2}=2.45\,\mathrm{rad/s};\;(c)\;K=ODO^{\mathsf{T}}\text{ 已写出};\;(d)\;x_{1,2}(t)\text{ 已写出，含拍频 }\Delta\omega=0.71\,\mathrm{rad/s}\)

例 12.5 把矩阵当作线性变换来"看"

设 \(A=\begin{pmatrix}2&1\\1&2\end{pmatrix}\)。把单位矢量 \(\hat{\imath}=(1,0)^{\mathsf{T}}\)、\(\hat{\jmath}=(0,1)^{\mathsf{T}}\) 与单位圆 \(x^{2}+y^{2}=1\) 在 \(A\) 下的像求出来，并从本征值/本征矢量的角度解释为何单位圆变成这种特定的椭圆。

解： \(A\) 作用于基矢量：\(A\hat{\imath}=\begin{pmatrix}2&1\\1&2\end{pmatrix}\begin{pmatrix}1\\0\end{pmatrix}=\begin{pmatrix}2\\1\end{pmatrix}\)（即 \(A\) 的第一列）；\(A\hat{\jmath}=\begin{pmatrix}2&1\\1&2\end{pmatrix}\begin{pmatrix}0\\1\end{pmatrix}=\begin{pmatrix}1\\2\end{pmatrix}\)（即 \(A\) 的第二列）。矩阵的列就是基矢量的像，这是把矩阵当作线性变换的核心。

单位圆 \((\cos\theta,\sin\theta)\) 的像：\(A(\cos\theta,\sin\theta)^{\mathsf{T}}=(2\cos\theta+\sin\theta,\,\cos\theta+2\sin\theta)^{\mathsf{T}}\)。它是 \(\mathbb{R}^{2}\) 中的一个椭圆。

本征值/本征矢量：\(\mathrm{tr}\,A=4\)，\(\det A=3\)，特征方程 \(\lambda^{2}-4\lambda+3=0\)，根 \(\lambda_{1}=3,\,\lambda_{2}=1\)。

\(\lambda_{1}=3\)：\((A-3I)=\begin{pmatrix}-1&1\\1&-1\end{pmatrix}\Rightarrow\vec{v}_{1}=\tfrac{1}{\sqrt{2}}(1,1)^{\mathsf{T}}\)。

\(\lambda_{2}=1\)：\((A-I)=\begin{pmatrix}1&1\\1&1\end{pmatrix}\Rightarrow\vec{v}_{2}=\tfrac{1}{\sqrt{2}}(1,-1)^{\mathsf{T}}\)。

解释：在 \(\vec{v}_{1}=(1,1)/\sqrt{2}\) 方向（\(45^{\circ}\)）上，\(A\) 把矢量拉长到 \(3\) 倍；在正交方向 \(\vec{v}_{2}=(1,-1)/\sqrt{2}\)（\(-45^{\circ}\)）上长度不变（\(\lambda=1\)）。所以单位圆变成长半轴 \(3\)、短半轴 \(1\)、长轴沿 \(45^{\circ}\) 的椭圆，面积为 \(\pi\cdot 3\cdot 1=3\pi=\pi\det A\) ✓。\(A\) 等价于"旋转 \(-45^{\circ}\)、沿 \(x\) 轴拉 3 倍、沿 \(y\) 轴不变、再转回"——即 \(A=ODO^{\mathsf{T}}\)，\(O\) 把坐标转 \(\pm 45^{\circ}\)、\(D=\mathrm{diag}(3,1)\)。

\(A\hat{\imath}=(2,1),\,A\hat{\jmath}=(1,2)\)；单位圆变为长半轴 \(3\) 沿 \(45^{\circ}\)、短半轴 \(1\) 沿 \(-45^{\circ}\) 的椭圆；面积 \(=3\pi=\pi\det A\)

⚠️ 常见误区 Common Pitfalls

  • 误以为矩阵乘法可交换。 一般 \(AB\neq BA\)。例如 \(\begin{pmatrix}0&1\\0&0\end{pmatrix}\begin{pmatrix}0&0\\1&0\end{pmatrix}=\begin{pmatrix}1&0\\0&0\end{pmatrix}\) 但反过来给 \(\begin{pmatrix}0&0\\0&1\end{pmatrix}\)。这不仅影响代数（\((A+B)^{2}=A^{2}+AB+BA+B^{2}\)，不是 \(A^{2}+2AB+B^{2}\)），也影响物理：量子力学中坐标 \(\hat{x}\) 与动量 \(\hat{p}\) 不对易（\([\hat{x},\hat{p}]=i\hbar\neq 0\)）正是不确定性原理的根源。
  • 看到 \(\det A=0\) 还硬求逆。 \(\det A=0\iff A\) 不可逆（"奇异" singular）。此时方程组 \(A\vec{x}=\vec{b}\) 要么无解（\(\vec{b}\) 不在列空间）要么有无穷多解（\(\vec{b}\) 在列空间，但解空间是一直线/平面）。在物理上 \(\det A=0\) 意味着系统丢失了一个自由度——例如简正模计算里出现零本征值对应"零模"（自由刚体平移或刚体转动）。
  • 把任意矩阵的本征矢量误以为彼此正交。 只有对称（或厄米）矩阵的不同本征值对应的本征矢量才正交（推导 12.3）。非对称矩阵（例 12.3）本征矢量一般不正交。物理上"主轴总正交"是因为惯量张量、刚度矩阵这类物理矩阵都是对称的——不是所有矩阵都有此福利。
  • 认为所有方阵都可对角化。 不可对角化的"亏损" (defective) 矩阵存在，最简单的例子是剪切矩阵 \(\begin{pmatrix}1&1\\0&1\end{pmatrix}\)：特征多项式 \((1-\lambda)^{2}=0\) 给出 \(\lambda=1\)（重根），但 \((A-I)=\begin{pmatrix}0&1\\0&0\end{pmatrix}\) 的零空间只有 \(1\) 维（\(\vec{v}\propto(1,0)\)），凑不出两个独立的本征矢量。对称矩阵永远可对角化是实谱定理的福音，但不要把它推广到一切矩阵。
  • 混淆"迹"与"行列式"作为唯一不变量。 \(2\times 2\) 矩阵的本征值由 \(\mathrm{tr}\,A\) 与 \(\det A\) 唯一决定（特征多项式 \(\lambda^{2}-(\mathrm{tr}\,A)\lambda+\det A\)），但 \(3\times 3\) 及以上还需要其他不变量（如 \(\sum\lambda_{i}\lambda_{j}\)）。不要无脑用 \(\mathrm{tr}\) 和 \(\det\) 套解所有尺寸的矩阵。

\(\lambda=\dfrac{2\cos\theta\pm\sqrt{4\cos^{2}\theta-4}}{2}=\cos\theta\pm i\sin\theta=e^{\pm i\theta}\)。
当 \(\theta\neq 0,\pi\) 时本征值是共轭复数 \(e^{\pm i\theta}\)，无实的本征矢量——几何上这意味着纯旋转不变任何实方向（除恒等变换 \(\theta=0\) 与反射型 \(\theta=\pi\)）。复本征值的模 \(\|e^{\pm i\theta}\|=1\) 说明旋转保长度。
\(\det R=1\)>0 保向，与"旋转不翻转空间"一致。事实上 \(R_{\theta}\) 是正交矩阵（\(R^{\mathsf{T}}R=I\)），所有正交矩阵的本征值模为 1，对应在复平面上单位圆上的转动。
本征值 \(\lambda=e^{\pm i\theta}\)（复数，模为 1）；实本征矢量仅 \(\theta=0\) 时存在；\(\det R_{\theta}=1\)（旋转保向保面积）

📝 本章小结 Summary & Key Formulas

  • 矩阵——矢量乘法：\((A\vec{x})_{i}=\sum_{j}A_{ij}x_{j}\)。矩阵——矩阵乘法：\((AB)_{ij}=\sum_{k}A_{ik}B_{kj}\)（行乘列）。\(AB\neq BA\) 一般成立。
  • 行列式：\(2\times 2\)，\(\det\begin{pmatrix}a&b\\c&d\end{pmatrix}=ad-bc\)。几何意义 = 列矢量张成的有向面积/体积。\(\det(AB)=\det A\cdot\det B\)。\(\det A=0\iff A\) 不可逆。
  • 逆矩阵：\(AA^{-1}=I\)。\(2\times 2\)：\(A^{-1}=\dfrac{1}{\det A}\begin{pmatrix}d&-b\\-c&a\end{pmatrix}\)。穿袜脱袜：\((AB)^{-1}=B^{-1}A^{-1}\)。
  • 高斯消元：对增广矩阵 \([A\,|\,\vec{b}]\) 做初等行变换化为上三角，再回代。本质是把 \(A\) 分解为 \(LU\)（下三角 × 上三角）。
  • 本征值问题：\(A\vec{v}=\lambda\vec{v}\)，\(\det(A-\lambda I)=0\)。\(2\times 2\)：\(\lambda^{2}-(\mathrm{tr}\,A)\lambda+\det A=0\)。
  • 对角化：\(A=PDP^{-1}\)，\(D\) 由本征值构成。对称矩阵 \(S=S^{\mathsf{T}}\) 总可正交对角化 \(S=ODO^{\mathsf{T}}\)，\(O\) 由正交归一本征矢量排成；不同本征值的本征矢量两两正交。
  • 物理应用：耦合振子 \(K\vec{a}=\omega^{2}m\vec{a}\) → 简正模频率 = \(\sqrt{\lambda_{i}/m}\)；惯量张量本征矢量 = 主轴，本征值 = 主转动惯量；量子力学中算符的本征态/本征值 = 测量结果。
\[ \boxed{\;A^{-1}=\frac{1}{\det A}\begin{pmatrix}d&-b\\-c&a\end{pmatrix},\qquad \det(A-\lambda I)=0,\qquad S=ODO^{\mathsf{T}}\;} \]
