物理中的数值方法 Numerical Methods in Physics

🎯 学习目标 Learning Objectives

学完本章后，你将能够：

  • 解释为什么绝大多数真实世界的常微分方程（双摆、非线性阻力、\(N\) 体问题）没有解析解 (closed-form solution)，必须依赖数值积分 (numerical integration)。
  • 把任意二阶常微分方程 \(\ddot{x}=f(x,\dot{x},t)\) 化为一阶方程组，并以状态矢量 (state vector) \(\vec{y}=(x,\dot{x})\) 为基本变量。
  • 写出显式欧拉法 (explicit / forward Euler) \(\vec{y}_{n+1}=\vec{y}_{n}+dt\,\vec{f}(t_{n},\vec{y}_{n})\)，识别它对振动与轨道系统的能量漂移 (energy drift) 与数值不稳性。
  • 推导并实现辛欧拉法 (symplectic Euler) 与速度 Verlet 法 (velocity Verlet)，说明为何它们对长期机械系统模拟近于能量守恒。
  • 使用四阶龙格–库塔法 (fourth-order Runge–Kutta, RK4)，写出四组斜率的加权平均，理解其 \(O(dt^{4})\) 局部截断误差与非辛性 (non-symplectic)。
  • 区分截断误差 (truncation error) 与舍入误差 (roundoff error)，通过收敛测试（减半 \(dt\)）验证数值方法的阶数。
  • 针对具体问题（分子动力学、轨道力学、一般初值问题）选择合适的积分方法并解释理由。

📖 核心概念 Core Concepts

1. 为什么需要数值方法？

经典力学告诉我们：给定力 \(\vec{F}\) 与初始条件，运动由 \(m\ddot{\vec{r}}=\vec{F}\) 决定。但能写出闭式解 (closed-form solution) 的问题只是沧海一粟：谐振子、单摆（小角近似）、开普勒椭圆——这些恰好是可积的特例。下面这些"真实"问题则无解析解：

  • 双摆 (double pendulum)：两个耦合的非线性方程，对初始条件高度敏感，呈现混沌 (chaos)；
  • 非线性阻力 (nonlinear drag)：\(\dot{v}=-g-kv|v|\) 的下落，速度的解析解虽为 \(\tanh\)，但加入高度依赖的空气密度后立刻无解；
  • \(N\) 体问题 (\(N\)-body problem)：太阳系动力学、星团演化、蛋白质折叠——除 \(N=2\) 外都没有闭式解。

对这些系统，物理学家求助于数值积分：在计算机上以离散时间步 \(t_{0},t_{1}=t_{0}+dt,\dots,t_{n}=t_{0}+n\,dt\) 逐步逼近 \(\vec{y}(t_{n})\)。本章介绍三种最重要的积分方法——欧拉、Verlet、RK4——并讨论它们的精度、稳定性与适用场景。

closed-form solution (解析解 / 闭式解), numerical integration (数值积分), chaos (混沌), \(N\)-body problem (\(N\) 体问题)

2. 把二阶 ODE 化为一阶方程组：状态矢量

牛顿方程是二阶的：\(\ddot{x}=f(x,\dot{x},t)/m\)。计算机更喜欢一阶方程组。技巧是引入速度 \(v=\dot{x}\) 作为独立变量，把一个二阶 ODE 改写为两个一阶 ODE：

\[ \dot{x}=v,\qquad \dot{v}=\frac{1}{m}f(x,v,t) \]

定义状态矢量 \(\vec{y}=(x,v)^{\top}\)，方程变为 \(\dot{\vec{y}}=\vec{F}(\vec{y},t)\)。这是初值问题 (initial-value problem, IVP) 的标准形式：给定 \(\vec{y}(0)=\vec{y}_{0}\)，求 \(\vec{y}(t)\)。

对二维运动，\(\vec{y}=(x,y,v_{x},v_{y})^{\top}\)，共 4 个分量。对 \(N\) 粒子的三维系统，\(\vec{y}\) 有 \(6N\) 维。所有方法都以 \(\dot{\vec{y}}=\vec{F}(\vec{y},t)\) 为输入。

state vector (状态矢量), initial-value problem IVP (初值问题), first-order system (一阶方程组)

3. 显式（前向）欧拉法

最简单的方案：用前向差分近似导数，\(\dot{\vec{y}}\approx(\vec{y}_{n+1}-\vec{y}_{n})/dt\)，把微分方程离散化为：

\[ \boxed{\;\vec{y}_{n+1}=\vec{y}_{n}+dt\,\vec{F}(t_{n},\vec{y}_{n})\;} \]

这是显式 (explicit) 方法：新状态直接由旧状态算出，无需解方程。局部截断误差 (local truncation error) 每步为 \(O(dt^{2})\)（来自泰勒展开中忽略的 \(\tfrac{1}{2}\ddot{\vec{y}}\,dt^{2}\)）；累积 \(N=T/dt\) 步后全局误差 (global error) 为 \(O(dt)\)，故欧拉法是一阶方法。

简单归简单，欧拉法对振动与轨道系统极其危险。考虑谐振子 \(\ddot{x}=-\omega^{2}x\)，状态 \(\vec{y}=(x,v)\)，更新矩阵：

\[ \begin{pmatrix}x_{n+1}\\ v_{n+1}\end{pmatrix}=\underbrace{\begin{pmatrix}1 & dt\\ -\omega^{2}dt & 1\end{pmatrix}}_{M}\begin{pmatrix}x_{n}\\ v_{n}\end{pmatrix} \]

特征值 \(\lambda=1\pm i\omega dt\)，模长 \(|\lambda|=\sqrt{1+\omega^{2}dt^{2}}>1\)。能量 \(E=\tfrac{1}{2}v^{2}+\tfrac{1}{2}\omega^{2}x^{2}\) 每步乘以 \(|\lambda|^{2}=1+\omega^{2}dt^{2}\)——指数增长！经过一个周期 \(T=2\pi/\omega\)，能量增大 \((1+\omega^{2}dt^{2})^{2\pi/(\omega dt)}\approx e^{\pi\omega dt}\) 倍。这是欧拉法的数值不稳性：误差不是衰减而是放大。

explicit/forward Euler (显式 / 前向欧拉法), local truncation error (局部截断误差), global error (全局误差), numerical instability (数值不稳性)

4. 半隐式（辛）欧拉与速度 Verlet

对力学系统，"位置更新用旧速度、速度更新用旧加速度"的朴素欧拉并非唯一选择。如果先更新速度再用新速度更新位置：

\[ v_{n+1}=v_{n}+dt\,a(x_{n}),\qquad x_{n+1}=x_{n}+dt\,v_{n+1} \]

这叫半隐式欧拉法 (semi-implicit Euler) 或辛欧拉法 (symplectic Euler)。对谐振子，其更新矩阵的行列式恰为 1（验证：\((1)(1)-dt(-\omega^{2}dt)=1\)），即保面积——这是辛积分 (symplectic integrator) 的标志。能量虽不能精确守恒，但有界地振荡，永不漂移。

更精确的辛方法是速度 Verlet (velocity Verlet)，由泰勒展开 \(x(t+dt)=x+vt+\tfrac{1}{2}a\,dt^{2}+\dots\) 截断至 \(dt^{2}\) 项得到：

\[ \boxed{\;x_{n+1}=x_{n}+v_{n}\,dt+\tfrac{1}{2}a_{n}\,dt^{2},\qquad v_{n+1}=v_{n}+\tfrac{1}{2}(a_{n}+a_{n+1})\,dt\;} \]

其中 \(a_{n}=a(x_{n})\) 由当前位置算出，\(a_{n+1}=a(x_{n+1})\) 由新位置算出。Verlet 是二阶方法（全局误差 \(O(dt^{2})\)），且辛——是分子动力学、轨道力学、游戏物理引擎的事实标准。

semi-implicit / symplectic Euler (半隐式 / 辛欧拉法), velocity Verlet (速度 Verlet 法), symplectic integrator (辛积分器), area-preserving (保面积)

5. 四阶龙格–库塔法（RK4）

RK4 是一般初值问题的通用主力 (workhorse)。它通过对 \(\dot{\vec{y}}=\vec{F}(\vec{y},t)\) 取四次斜率采样并加权平均，达到 \(O(dt^{4})\) 的全局精度：

\[ \begin{aligned} \vec{k}_{1}&=\vec{F}(t_{n},\,\vec{y}_{n})\\ \vec{k}_{2}&=\vec{F}\!\bigl(t_{n}+\tfrac{dt}{2},\,\vec{y}_{n}+\tfrac{dt}{2}\vec{k}_{1}\bigr)\\ \vec{k}_{3}&=\vec{F}\!\bigl(t_{n}+\tfrac{dt}{2},\,\vec{y}_{n}+\tfrac{dt}{2}\vec{k}_{2}\bigr)\\ \vec{k}_{4}&=\vec{F}\!\bigl(t_{n}+dt,\,\vec{y}_{n}+dt\,\vec{k}_{3}\bigr) \end{aligned}\qquad \vec{y}_{n+1}=\vec{y}_{n}+\frac{dt}{6}\bigl(\vec{k}_{1}+2\vec{k}_{2}+2\vec{k}_{3}+\vec{k}_{4}\bigr) \]

权重 \(1:2:2:1\) 来源于辛普森积分，使方法恰好匹配泰勒展开至 \(dt^{4}\)。每步调用 4 次 \(\vec{F}\)，比欧拉贵 4 倍——但每步精度高得多。注意：RK4 不是辛方法。在保守系统中，它的能量在每步附近几乎完美，但 缓慢单调漂移，时间足够长（数千个周期）会偏离。这正是辛积分器存在的理由。

Runge–Kutta RK4 (龙格–库塔法), workhorse method (通用主力), Simpson's rule (辛普森积分)

6. 步长 \(dt\)：精度、代价与稳定性

步长 \(dt\) 是数值方法的核心旋钮。两个相反的考量：

  • 精度：减小 \(dt\) ⇒ 全局误差 \(\propto dt^{p}\) 下降（\(p\) 为方法阶数）。
  • 代价：达到时间 \(T\) 所需步数 \(N=T/dt\) 增加，计算时间随之增加。

但 \(dt\) 还有稳定性上限：太大时数值解指数发散，误差非但不减反而放大。对显式欧拉作用于振动系统，稳定的必要条件是 \(\omega dt<2\)（更新矩阵特征值不超 1）；当 \(\omega dt=\pi\)（每步跨越半个周期）时，方法完全失效。对刚性系统 (stiff systems，如快慢时间尺度耦合的化学反应)，显式方法的稳定步长可能小到不切实际，需用隐式方法（此处不展开）。

自适应步长 (adaptive step size)：用两种阶数的方法（或同方法两种步长）估计局部误差，自动放大/缩小 \(dt\)——误差大时缩步、误差小时放步。RK4(5)（Dormand–Prince）是最常见的自适应方案。

step size (步长), stability limit (稳定性上限), stiff system (刚性系统), adaptive step size (自适应步长)

7. 截断误差 vs 舍入误差

数值误差有两类：

  • 截断误差 (truncation error)：来自算法本身（泰勒级数在某阶截断）。每步 \(O(dt^{p+1})\)，累积 \(O(dt^{p})\)。随 \(dt\to 0\) 而趋于零。
  • 舍入误差 (roundoff error)：来自浮点数有限精度（双精度 \(\varepsilon\approx 2.2\times10^{-16}\)）。每步加减产生的随机误差 \(\sim\varepsilon|\vec{y}|\)，\(N\) 步累积（随机游走）\(\sim\varepsilon|\vec{y}|\sqrt{N}\)。随 \(dt\to 0\)（即 \(N\to\infty\)）而上升。

总误差 \(E_{\text{tot}}(dt)\approx A\,dt^{p}+B\,\varepsilon/\sqrt{dt}\)，存在最优 \(dt\)。对 RK4（\(p=4\)），\(dt_{\text{opt}}\sim\varepsilon^{2/9}\approx 2\times10^{-4}\)——通常远大于实用步长，故舍入很少是瓶颈。但对欧拉法（\(p=1\)），\(dt_{\text{opt}}\sim\varepsilon^{2/3}\approx 5\times10^{-11}\)，更接近实用区间。"越小越好"并不永远成立。

truncation error (截断误差), roundoff error (舍入误差), machine epsilon (机器精度), optimal step size (最优步长)

8. 实用建议：为问题选对方法

问题类型 推荐方法 理由
分子动力学 / 轨道长期演化 Verlet 族（辛） 能量有界、相空间体积守恒
一般初值问题（要求精度） RK4（或自适应 RK4(5)） 高阶、易实现、普适
实时游戏 / 视觉仿真 半隐式 Euler 或 Verlet 便宜、稳定、能量可控
刚性系统（快慢尺度耦合） 隐式方法（BDF 等） 显式方法稳定步长过小
保守 Hamilton 系统（理论） 辛积分器（辛 Euler / Verlet / 辛 RK） 长期保持近能量守恒

🔭 推导 Derivation

推导 20.1：由泰勒展开导出速度 Verlet 公式

步骤 1（位置展开至 \(dt^{2}\)）： 对位置 \(x(t)\) 作泰勒展开：

\[ x(t+dt)=x(t)+\dot{x}(t)\,dt+\tfrac{1}{2}\ddot{x}(t)\,dt^{2}+O(dt^{3}) \]

代入 \(\dot{x}=v\)，\(\ddot{x}=a\)，截断至 \(dt^{2}\)：

\[ x_{n+1}=x_{n}+v_{n}\,dt+\tfrac{1}{2}a_{n}\,dt^{2}+O(dt^{3}) \]

步骤 2（速度展开至 \(dt\)，再修正）： 朴素地 \(v_{n+1}=v_{n}+a_{n}\,dt\) 只有一阶精度。要达到二阶，必须把"区间 \([t,t+dt]\) 内的加速度"用梯形规则平均：

\[ v_{n+1}=v_{n}+\tfrac{1}{2}(a_{n}+a_{n+1})\,dt+O(dt^{3}) \]

步骤 3（实现顺序）： 注意 \(a_{n+1}=a(x_{n+1})\) 依赖于新位置，故实现顺序为：(i) 用 \(a_{n}\) 算 \(x_{n+1}\)；(ii) 用 \(x_{n+1}\) 算 \(a_{n+1}\)；(iii) 用 \((a_{n},a_{n+1})\) 的平均更新 \(v\)。这正是"速度 Verlet"算法。

步骤 4（验证二阶精度）： 把 \(x_{n+1}\) 的表达式取泰勒展开到 \(dt^{3}\)，并把 \(v_{n+1}\) 表达式同样展开，再代入 \(\dot{\vec{y}}=\vec{F}\) 的精确解 \(\vec{y}(t+dt)\)，比较系数：两者匹配到 \(dt^{2}\) 项，差异为 \(O(dt^{3})\)。每步局部误差 \(O(dt^{3})\)，全局累积 \(O(dt^{2})\) ⇒ 二阶方法。

步骤 5（验证辛性 / 保面积）： 对谐振子 \(\ddot{x}=-\omega^{2}x\)，速度 Verlet 的更新矩阵为（见核心概念 §4）：

\[ M=\begin{pmatrix}1-\tfrac{\omega^{2}dt^{2}}{2} & dt\\[2pt] -\omega^{2}dt\bigl(1-\tfrac{\omega^{2}dt^{2}}{4}\bigr) & 1-\tfrac{\omega^{2}dt^{2}}{2}\end{pmatrix} \]

计算行列式：\(\det M=(1-\tfrac{\omega^{2}dt^{2}}{2})^{2}+\omega^{2}dt^{2}(1-\tfrac{\omega^{2}dt^{2}}{4})=1-\omega^{2}dt^{2}+\tfrac{\omega^{4}dt^{4}}{4}+\omega^{2}dt^{2}-\tfrac{\omega^{4}dt^{4}}{4}=1\)。\(\det M=1\)——相空间中任意区域面积守恒，正是辛映射的定义。这正是 Verlet 对机械系统能量"不漂移只振荡"的几何根源。

推导 20.2：显式欧拉作用于谐振子的能量增长因子

对谐振子 \(\ddot{x}=-\omega^{2}x\)，显式欧拉的更新矩阵 \(M=\begin{pmatrix}1 & dt\\ -\omega^{2}dt & 1\end{pmatrix}\)，特征方程 \(\lambda^{2}-2\lambda+(1+\omega^{2}dt^{2})=0\)，特征值 \(\lambda=1\pm i\omega dt\)，模长平方：

\[ |\lambda|^{2}=(1)^{2}+(\omega dt)^{2}=1+\omega^{2}dt^{2} \]

能量 \(E_{n}\propto x_{n}^{2}+(v_{n}/\omega)^{2}\) 是 \((x,v/\omega)\) 平面中矢量长度的平方，而该矢量每步被 \(M\) 作用——其长度平方乘以 \(|\lambda|^{2}\)。故 \(E_{n+1}=(1+\omega^{2}dt^{2})\,E_{n}\)，每步乘以同一因子 ⇒ 几何级数：

\[ E_{n}=E_{0}\,(1+\omega^{2}dt^{2})^{n} \]

经过一个周期 \(T=2\pi/\omega\)，\(n=T/dt=2\pi/(\omega dt)\) 步，能量因子为 \((1+\omega^{2}dt^{2})^{2\pi/(\omega dt)}\)。利用 \((1+u)^{1/u}\to e\)：

\[ \frac{E_{T}}{E_{0}}\xrightarrow{dt\to 0}e^{\pi\omega dt}\quad(\text{每周期增长因子}) \]

例如 \(\omega=1,\,dt=0.2\)：\(e^{0.628}\approx 1.85\)，每周期能量涨 85%；5 个周期后涨 \(1.85^{5}\approx 22\) 倍。这是数值不稳性的清晰例子：误差不衰减而指数增长，与真实物理（能量严格守恒）矛盾。

✏️ 典型例题 Worked Examples

例 20.1 谐振子：欧拉、Verlet、RK4 长期能量比较

谐振子 \(m=1.0\,\mathrm{kg}\)，\(k=1.0\,\mathrm{N/m}\)（\(\omega=1.0\,\mathrm{rad/s}\)，周期 \(T=2\pi\,\mathrm{s}\)）。初始 \(x_{0}=1.0\,\mathrm{m}\)，\(v_{0}=0\)，故 \(E_{0}=\tfrac{1}{2}kx_{0}^{2}=0.50\,\mathrm{J}\)。取步长 \(dt=0.20\,\mathrm{s}\)，分别用 (a) 显式欧拉、(b) 速度 Verlet、(c) RK4 各积分 5 个周期（\(t_{\text{f}}=10\pi\approx 31.4\,\mathrm{s}\)，约 157 步）。求各方法在终点的振幅与能量，并说明现象。

(a) 显式欧拉： 由推导 20.2，每步能量乘以 \((1+\omega^{2}dt^{2})=1.04\)。经过 5 个周期（\(n=5T/dt=5\times 2\pi/0.2\approx 157\) 步）：

\[ E_{\text{f}}=E_{0}\,(1.04)^{157}=0.50\times e^{157\ln 1.04}=0.50\times e^{6.16}=0.50\times 474=237\,\mathrm{J} \]

振幅 \(A_{\text{f}}=\sqrt{2E_{\text{f}}/k}=\sqrt{474}=21.8\,\mathrm{m}\)。振幅从 \(1\,\mathrm{m}\) 涨到 \(22\,\mathrm{m}\)，与真实谐振子（振幅应恒为 \(1\,\mathrm{m}\)）差 22 倍——欧拉法完全不靠谱。

(b) 速度 Verlet： 由 \(\det M=1\)（推导 20.1 步骤 5），能量在每步有界振荡，振幅 \(\sim O(dt^{2})\approx 4\%\)。具体地，能量在区间 \(E_{0}[1\pm\tfrac{\omega dt}{2}]\approx[0.45,\,0.55]\,\mathrm{J}\) 内来回振荡，5 个周期后回到 \(E\approx 0.50\,\mathrm{J}\)。振幅始终在 \([0.97,\,1.03]\,\mathrm{m}\) 之间。近完美能量守恒（仅有微小相位/频率偏移：数值频率 \(\omega_{\text{num}}=\tfrac{2}{dt}\arcsin(\omega dt/2)=1.00083\,\mathrm{rad/s}\)，相对误差 \(8\times10^{-4}\)）。

(c) RK4： RK4 是四阶方法，每步局部误差 \(O(dt^{5})\)，全局 \(O(dt^{4})=0.2^{4}=1.6\times10^{-3}\)。在 5 个周期内能量偏差 \(|\Delta E|/E_{0}\lesssim 10^{-3}\)，即 \(E_{\text{f}}=0.500\pm 0.001\,\mathrm{J}\)。振幅 \(\approx 1.000\,\mathrm{m}\)。在 5 个周期尺度上 RK4 与 Verlet 看起来一样完美；它们的区别要在数千个周期后才显现（见下文）。

(d) 长期对比（数千个周期）： 把积分推到 \(10^{4}\) 个周期（\(\approx 6.3\times10^{4}\,\mathrm{s}\)，\(N\approx 3.1\times10^{5}\) 步）。Verlet 能量仍在 \(0.50\pm 0.02\,\mathrm{J}\) 内振荡；RK4 能量则缓慢线性漂移，累积偏差约 \(10^{-2}\,\mathrm{J}\)（占 2%）。这是 RK4 非辛性的体现：短期无敌，长期输给辛方法。

欧拉：\(E_{\text{f}}\approx 237\,\mathrm{J}\)，\(A_{\text{f}}\approx 21.8\,\mathrm{m}\)（指数发散，不可用）；Verlet：\(E_{\text{f}}\approx 0.50\pm 0.02\,\mathrm{J}\)，\(A_{\text{f}}\approx 1.00\,\mathrm{m}\)（辛、能量有界）；RK4：\(E_{\text{f}}=0.500\pm 0.001\,\mathrm{J}\)，\(A_{\text{f}}\approx 1.000\,\mathrm{m}\)（短期极准，长期慢漂）

例 20.2 二维开普勒轨道：欧拉使轨道"螺旋外飞"

单位质量粒子在中心引力 \(\vec{a}=-GM\vec{r}/r^{3}\) 下运动，\(GM=1\)（无量纲；可视为 SI 比例）。初始 \((x_{0},y_{0})=(1,0)\)，\((v_{x0},v_{y0})=(0,1)\)——这是半径 \(r=1\) 的圆轨道，速度恰为 \(v_{\text{circ}}=\sqrt{GM/r}=1\)，周期 \(T=2\pi\sqrt{r^{3}/GM}=2\pi\)。机械能（每单位质量）\(E_{0}=\tfrac{1}{2}v^{2}-GM/r=\tfrac{1}{2}-1=-\tfrac{1}{2}\)。取 \(dt=0.10\)，分别用显式欧拉、速度 Verlet、RK4 积分一个周期，描述结果。

(a) 显式欧拉——能量注入： 第一步（\((x,y,v_{x},v_{y})=(1,0,0,1)\)）：

\[ \vec{a}_{0}=-\frac{(1,0)}{1^{3}}=(-1,0) \]

欧拉更新：\(x_{1}=1+0.1\times 0=1\)，\(y_{1}=0+0.1\times 1=0.1\)，\(v_{x,1}=0+0.1\times(-1)=-0.1\)，\(v_{y,1}=1+0.1\times 0=1\)。新位置 \(r_{1}=\sqrt{1+0.01}=1.00499\)，新速率 \(v_{1}=\sqrt{0.01+1}=1.00499\)。新能量：

\[ E_{1}=\tfrac{1}{2}(1.00499)^{2}-\frac{1}{1.00499}=0.5050-0.99504=-0.49004 \]

每步 \(\Delta E\approx+0.00996\)（约 \(+2\%\)）。线性外推，经过一个周期 \(n=2\pi/0.1\approx 63\) 步，\(\Delta E\approx+0.627\)，给出 \(E_{T}\approx -0.5+0.627=+0.13\)——能量变正 ⇒ 粒子摆脱束缚！实际积分显示：欧拉轨道从圆轨道螺旋外飞，几个周期后逃离到无穷远。

(b) 速度 Verlet——闭合椭圆： 辛性保证 \(E\) 有界振荡。每步 \(\Delta E\) 时正时负相互抵消，一个周期后 \(E_{T}=-0.500\pm 0.005\)。轨道保持闭合（数值上略有进动，因 Verlet 给出的"数值频率"与真实不同，但偏差 \(\sim O(dt^{2})=1\%\)）。"螺旋外飞"现象完全消失。

(c) RK4——近乎完美： 每步局部误差 \(O(dt^{5})=10^{-5}\)，一个周期累积误差 \(\sim 6\times10^{-4}\)。能量 \(E_{T}=-0.4997\)，与 \(E_{0}\) 几乎不可区分。轨道在视觉上与真实椭圆重合。

结论： 对力学系统（保守、长期演化），Verlet（或更一般的辛方法）是首选。RK4 适合需要短期高精度的场合，但对超长积分（如太阳系 10⁹ 年演化）的辛性缺失会显现。显式欧拉几乎从不应被使用——它的简单被其不稳定性远远抵消。

欧拉：\(E\) 单调上升，每周期 \(\Delta E\approx+0.628\)，\(E>0\) 后逃逸（轨道螺旋外飞）；Verlet：\(E_{T}=-0.500\pm 0.005\)（辛、闭合）；RK4：\(E_{T}\approx-0.4997\)（短期最准）

例 20.3 收敛测试：减半 \(dt\)，验证方法阶数

解 \(y'=-y\)，\(y(0)=1\)，到 \(t=1\)。精确解 \(y(t)=e^{-t}\)，\(y(1)=0.3678794412\)。分别用显式欧拉与 RK4，\(dt=0.1,\,0.05,\,0.025,\,0.0125\)，列表给出误差与误差比，验证方法的阶。

显式欧拉： 迭代 \(y_{n+1}=(1-dt)\,y_{n}\)，故 \(y_{N}=(1-dt)^{N}\)，\(N=1/dt\)。

\[ \begin{array}{c|c|c|c} dt & y_{N} & |错误| & \text{比上一行}\\\hline 0.1 & 0.9^{10}=0.34867844 & 1.920\times10^{-2} & -\\ 0.05 & 0.95^{20}=0.35848592 & 9.394\times10^{-3} & 2.04\\ 0.025 & 0.975^{40}=0.36316799 & 4.711\times10^{-3} & 1.99\\ 0.0125 & 0.9875^{80}=0.36551676 & 2.363\times10^{-3} & 1.99 \end{array} \]

误差比稳定在 \(\approx 2\)，对应 \(O(dt^{1})\)（\(dt\to dt/2\) 时误差减半）⇒ 欧拉是一阶方法 ✓。

RK4： 对 \(f(y)=-y\)，单步更新可显式化简（推导见练习 5）：

\[ y_{n+1}=y_{n}\Bigl(1-dt+\tfrac{dt^{2}}{2}-\tfrac{dt^{3}}{6}+\tfrac{dt^{4}}{24}\Bigr) \]

这正是 \(e^{-dt}\) 的四阶泰勒近似。每步误差 \(\sim dt^{5}/120\)。列表如下：

\[ \begin{array}{c|c|c|c} dt & y_{N} & |错误| & \text{比上一行}\\\hline 0.1 & 0.3678793 & 8.3\times10^{-8} & -\\ 0.05 & 0.367879438 & 5.2\times10^{-9} & 16.0\\ 0.025 & 0.36787944117 & 3.3\times10^{-10} & 15.9\\ 0.0125 & 0.36787944117 & 2.1\times10^{-11} & 15.9 \end{array} \]

误差比稳定在 \(\approx 16=2^{4}\)，对应 \(O(dt^{4})\)（\(dt\to dt/2\) 时误差减少 \(2^{4}=16\) 倍）⇒ RK4 是四阶方法 ✓。在 \(dt=0.1\) 时，RK4 已达 \(10^{-7}\) 精度，欧拉则只有 \(10^{-2}\)——同样步长下 RK4 比 Euler 精确 \(10^{5}\) 倍。

实务指导： 看到"减半 \(dt\)，误差比是否如预期"是验证代码与方法的黄金标准。如果误差比不接近 \(2^{p}\)，可能代码有 bug，或处于舍入误差主导区。

欧拉误差比 \(\approx 2\)（一阶）；RK4 误差比 \(\approx 16\)（四阶）。同 \(dt=0.1\) 下 RK4 比 Euler 精确约 \(10^{5}\) 倍

例 20.4 二次阻尼下落：数值求解收尾速度

质量 \(m=1.0\,\mathrm{kg}\) 的物体在重力（\(g=9.80\,\mathrm{m/s^{2}}\)）与二次空气阻力 \(-kv|v|\)（\(k=0.40\,\mathrm{kg/m}\)）下从静止下落（取向下为负）。运动方程 \(m\dot{v}=-mg-kv|v|\)，即 \(\dot{v}=-9.80-0.40\,v|v|\)。收尾速度 (terminal velocity) 是 \(\dot{v}=0\) 时的恒定速度。求 \(v_{t}\)，并用 RK4 数值积分 3 秒验证 \(v(t)\to v_{t}\)。

解析收尾速度： 令 \(\dot{v}=0\)，\(-9.80-0.40\,v_{t}|v_{t}|=0\)。下落时 \(v<0\)，故 \(v_{t}|v_{t}|=-v_{t}^{2}\)，方程变为 \(-9.80+0.40\,v_{t}^{2}=0\)：

\[ v_{t}=-\sqrt{\frac{g}{k/m}}=-\sqrt{\frac{9.80}{0.40}}=-\sqrt{24.5}=-4.9497\,\mathrm{m/s} \]

取负号表示向下。注意：纯二次阻尼下速度其实有解析解 \(v(t)=v_{t}\tanh(gt/|v_{t}|)\)（参考练习 4），但若阻力律偏离二次（如线性 + 二次混合，或 \(k\) 随高度/速度变化），数值方法是唯一可行途径。我们此处用数值法验证最简单的二次情形。

RK4 积分（\(dt=0.5\,\mathrm{s}\)）： 右端函数 \(f(v)=-9.80-0.40\,v|v|\)。第一步 \(v_{0}=0\)：

\[ \begin{aligned} k_{1}&=f(0)=-9.80\\ k_{2}&=f(0+0.25\,k_{1})=f(-2.45)=-9.80+0.40(2.45)^{2}=-7.40\\ k_{3}&=f(0+0.25\,k_{2})=f(-1.85)=-9.80+0.40(1.85)^{2}=-8.43\\ k_{4}&=f(0+0.5\,k_{3})=f(-4.215)=-9.80+0.40(4.215)^{2}=-2.70 \end{aligned} \]
\[ v_{1}=0+\frac{0.5}{6}(-9.80-14.80-16.86-2.70)=\frac{0.5}{6}(-44.16)=-3.680\,\mathrm{m/s} \]

解析值 \(v(0.5)=v_{t}\tanh(0.5\times9.80/4.9497)=-4.9497\tanh(0.990)=-4.9497\times0.7587=-3.755\,\mathrm{m/s}\)。RK4 一步误差仅 \(0.075\,\mathrm{m/s}\)（\(2\%\)）——已经很好，且 RK4 误差随 \(dt\to 0\) 以 \(O(dt^{4})\) 下降。

用更小步长 \(dt=0.10\,\mathrm{s}\) 积分 3 秒： 结果（每 0.5 s 报告一次）：

\[ \begin{array}{c|c|c} t\,(\mathrm{s}) & v_{\text{RK4}}\,(\mathrm{m/s}) & v_{\text{解析}}\,(\mathrm{m/s})\\\hline 0.0 & 0 & 0\\ 0.5 & -3.755 & -3.755\\ 1.0 & -4.758 & -4.758\\ 1.5 & -4.935 & -4.935\\ 2.0 & -4.985 & -4.985\\ 3.0 & -4.9497 & -4.9497\;\checkmark \end{array} \]

RK4 与解析解在 4 位有效数字上完全一致。\(t\approx 2\,\mathrm{s}\)（约 4 个时间常数 \(\tau=|v_{t}|/g\approx 0.5\,\mathrm{s}\)）时速度已收敛到 \(v_{t}\) 的 99%；\(t=3\,\mathrm{s}\) 时已精确到 5 位有效数字。收尾速度 \(-4.95\,\mathrm{m/s}\)（向下）。

\(v_{t}=-\sqrt{g/(k/m)}=-4.95\,\mathrm{m/s}\)（向下）；RK4 数值解 \(v(3\,\mathrm{s})=-4.9497\,\mathrm{m/s}\)，与解析解 5 位有效数字一致

例 20.5 截断 vs 舍入：最优步长的估计

用某种 \(p\) 阶方法积分 \(\dot{y}=f(y)\) 到固定时间 \(T\)，总误差模型为 \(E_{\text{tot}}(dt)\approx A\,dt^{p}+B\,\varepsilon/\sqrt{dt}\)，其中 \(\varepsilon=2.2\times10^{-16}\) 为机器精度，\(A\sim B\sim 1\)。分别估计 (a) 欧拉（\(p=1\)）、(b) RK4（\(p=4\)）的最优步长 \(dt_{\text{opt}}\)，并解释物理意义。

步骤 1（最小化总误差）： 令 \(\dv{E_{\text{tot}}}{dt}=0\)：

\[ pA\,dt^{p-1}-\frac{B\varepsilon}{2\,dt^{3/2}}=0\quad\Longrightarrow\quad dt^{p+1/2}=\frac{B\varepsilon}{2pA} \]
\[ \boxed{\;dt_{\text{opt}}=\Bigl(\frac{B\varepsilon}{2pA}\Bigr)^{\!2/(2p+1)}\;} \]

(a) 欧拉（\(p=1\)）： 取 \(A=B=1\)：

\[ dt_{\text{opt}}=\bigl(\tfrac{\varepsilon}{2}\bigr)^{2/3}=(1.1\times10^{-16})^{2/3}\approx 4.9\times10^{-11}\,\mathrm{s} \]

(b) RK4（\(p=4\)）：

\[ dt_{\text{opt}}=\bigl(\tfrac{\varepsilon}{8}\bigr)^{2/9}=(2.75\times10^{-17})^{2/9}\approx 1.7\times10^{-4}\,\mathrm{s} \]

解释： 对欧拉法，\(dt_{\text{opt}}\) 约 \(10^{-11}\)——比任何实际应用小得多。这意味着对欧拉法，舍入误差几乎从不构成瓶颈（你永远会用比这大得多的 \(dt\)，截断占主导）。对 RK4，\(dt_{\text{opt}}\approx 10^{-4}\)——意味着如果你把 \(dt\) 减到 \(10^{-5}\) 或更小，舍入误差开始压过截断误差，进一步减小 \(dt\) 不仅无益反而有害。

教训： 高阶方法在"理论上可任意精确"的同时，受舍入误差的硬性下限约束。对长期或大量步数的积分，应考虑Kahan 求和或更高精度算术（quad precision）。

\(dt_{\text{opt}}^{(\text{Euler})}\approx 5\times10^{-11}\)；\(dt_{\text{opt}}^{(\text{RK4})}\approx 2\times10^{-4}\)。低阶方法几乎不受舍入限制；高阶方法在很小 \(dt\) 下舍入会主导

⚠️ 常见误区 Common Pitfalls

  • 用显式欧拉积分振动或轨道系统。显式欧拉对 \(\ddot{x}=-\omega^{2}x\) 给出特征值模长 \(|\lambda|=\sqrt{1+\omega^{2}dt^{2}}>1\)，能量每步乘以 \(1+\omega^{2}dt^{2}\)，几何级数发散。结果是振幅指数增长、轨道螺旋外飞——纯数值假象，与真实物理（能量守恒）相反。对任何保守力学系统，永远首选辛方法（Verlet 等），不要用朴素欧拉。
  • "\(dt\) 越小一定越准"。这只在截断误差主导时成立。一旦 \(dt\) 接近 \(dt_{\text{opt}}\)（见例 20.5），舍入误差开始上升，减半 \(dt\) 反而让总误差变大。对 RK4，这一拐点在 \(dt\sim10^{-4}\)，并非不可触及。任何"看到误差不再下降"的现象都应怀疑是舍入主导。
  • 把 RK4 当成"万能且永远最优"。RK4 短期无敌，但不是辛方法：对谐振子或开普勒轨道积分 \(10^{4}\) 个周期，能量会缓慢线性漂移（虽小但不归零）。而 Verlet（辛）的能量有界振荡、永不漂移。长期演化（行星轨道、分子动力学、银河系模拟）必须用辛方法。
  • 忘了做收敛测试。不通过"减半 \(dt\)，结果是否如预期收敛"验证的数值结果不能信赖。常见错误：选定 \(dt\) 后直接报告结果，未确认这是 \(dt\to 0\) 的渐近行为。每次报告数值解都应附带"用 \(dt/2\) 重做一次，结果变化 \(\Delta\)"——\(\Delta\) 给出实际精度的经验估计。
  • 把"局部误差阶 \(p+1\)"与"全局误差阶 \(p\)"混淆。欧拉单步误差 \(O(dt^{2})\)，但累积 \(N=T/dt\) 步后全局误差 \(O(dt)\)，所以是一阶方法。RK4 单步 \(O(dt^{5})\)，全局 \(O(dt^{4})\)，是四阶方法。文献中"方法阶数"通常指全局阶数。
  • 对刚性系统（stiff）仍坚持显式方法。快慢时间尺度耦合（如化学反应动力学、电路瞬态）下，显式方法的稳定步长受快尺度限制，可能小到 \(10^{-8}\,\mathrm{s}\)，而物理上关心的是慢尺度（\(1\,\mathrm{s}\)）。此时显式方法代价巨大，应换隐式方法（BDF、隐式 RK）。

变量分离：\(\dv{v}{t}=-(g/v_{t}^{2})(v^{2}-v_{t}^{2})\)（注意 \(v_{t}<0\)，\(v^{2}>v_{t}^{2}\) 时 \(\dot{v}<0\)）。令 \(u=|v|/|v_{t}|\)，分离变量积分。

令 \(w_{t}=\sqrt{mg/k}=|v_{t}|\)，则 \(g+(k/m)w^{2}=(g/w_{t}^{2})(w_{t}^{2}+w^{2})\)。积分：
\(\int_{0}^{w}\dfrac{dw'}{w_{t}^{2}+w'^{2}}\cdot\dfrac{w_{t}^{2}}{g}=\int_{0}^{t}dt'\)

\(v(t)=v_{t}\tanh(gt/|v_{t}|)\)，\(v_{t}=-\sqrt{mg/k}\)；混合阻力律给出三次非线性 ODE，无可解析解，必数值求解

对线性 \(\dot{y}=\lambda y\)，RK4 的四级可显式求和。
对 \(f(y)=\lambda y\)：
\(k_{1}=\lambda y_{n}\)
\(k_{2}=\lambda(y_{n}+\tfrac{dt}{2}k_{1})=\lambda y_{n}(1+\tfrac{\lambda dt}{2})\)

📝 本章小结 Summary & Key Formulas

  • 真实世界的 ODE 大多没有解析解，必须用数值积分。把 \(\ddot{x}=f(x,\dot{x},t)\) 化为状态矢量 \(\vec{y}=(x,\dot{x})\) 的一阶方程组 \(\dot{\vec{y}}=\vec{F}(\vec{y},t)\) 是所有方法的统一形式。
  • 显式欧拉 \(\vec{y}_{n+1}=\vec{y}_{n}+dt\,\vec{F}(t_{n},\vec{y}_{n})\)：一阶、最简单，但对振动/轨道系统能量指数发散（\(E_{n+1}/E_{n}=1+\omega^{2}dt^{2}\)），几乎不应被使用。
  • 半隐式 / 辛欧拉 与 速度 Verlet：辛方法（\(\det M=1\)，保相空间面积），能量有界振荡、永不漂移。Verlet 是二阶方法，是分子动力学、轨道力学、游戏引擎的事实标准。
  • RK4 \(\vec{y}_{n+1}=\vec{y}_{n}+\tfrac{dt}{6}(\vec{k}_{1}+2\vec{k}_{2}+2\vec{k}_{3}+\vec{k}_{4})\)：四阶、短期最准、通用主力；但非辛，长期缓慢能量漂移。
  • 步长 \(dt\)：精度（截断 \(O(dt^{p})\)）vs 代价（\(N=T/dt\)）vs 稳定性（显式方法有 \(\omega dt\) 上限）的权衡。自适应步长可自动调节。
  • 两类误差：截断（随 \(dt\to 0\) 减小）vs 舍入（随 \(dt\to 0\) 上升）。最优 \(dt_{\text{opt}}\sim\varepsilon^{2/(2p+1)}\)：低阶方法几乎不受舍入限制；高阶方法在很小 \(dt\) 下舍入主导。
  • 方法选择：长期保守系统选辛（Verlet）；一般初值问题选 RK4（或自适应 RK4(5)）；实时仿真选半隐式 Euler；刚性系统选隐式方法。
  • 收敛测试是数值结果的黄金校验：减半 \(dt\)，全局误差应减少 \(2^{p}\) 倍；否则代码有 bug 或舍入主导。
