藤校大一物理 · 上学期 Ivy-League Freshman Physics — First Semester

一套交互式、双语（中文 + English）的荣誉级大一物理上学期教程，覆盖牛顿力学、分析力学、狭义相对论、流体力学与进阶专题，配以可运行的互动仿真。
An interactive, bilingual (中文 + English), honors-level first-semester physics tutorial covering Newtonian & analytical mechanics, special relativity, fluids, and advanced topics — each chapter pairs rigorous derivations with runnable interactive simulations.

如何使用本教程 / How to use this tutorial

每一章都包含：学习目标、核心概念、推导、典型例题、常见误区、练习题，以及一个可调节参数的互动仿真。 使用左侧的 侧边栏 在 20 章 + 附录之间导航；点击 ☾ 深色 / ☀ 浅色 切换深色模式。

Each chapter includes learning objectives, core concepts, derivations, worked examples, common pitfalls, practice problems, and a runnable interactive simulation. Use the sidebar to navigate all 20 chapters and the appendix; toggle dark mode from the sidebar.
